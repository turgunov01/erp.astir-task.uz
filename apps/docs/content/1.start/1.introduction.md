Astir ERP — производственная система анимационной студии. В одном месте собраны проекты и их структура (эпизоды, сцены, шоты), задачи художников, версии и согласование с клиентом, правки, очередь рендера, библиотека ассетов, команда и её рабочее время, клиенты, деньги студии и отчёты.

![Панель управления Astir ERP](/screenshots/dashboard.png)

::note
Если открыть адрес раздела, на который у вас нет права (например, по старой ссылке), приложение покажет страницу «Нет доступа» с текстом «У вас нет доступа к этому разделу».
::

## Языки интерфейса

Интерфейс работает на четырёх языках:

| Код | Язык |
| --- | --- |
| `ru` | Русский |
| `uz` | O‘zbekcha |
| `en` | English |
| `tr` | Türkçe |

Где переключить язык:

- **На странице входа** — выпадающий список в правом верхнем углу. Выбор запоминается только в этом браузере.
- **В меню пользователя** — нажмите на своё имя в правом верхнем углу и выберите «Язык». Интерфейс переключается сразу, а выбор сохраняется в вашей учётной записи. Подробнее — в разделе [Шапка и меню](/start/interface).
- **В профиле** — там же можно выбрать вариант «Как в студии»: тогда используется язык по умолчанию из настроек студии. См. [Профиль](/work/profile).

Язык по умолчанию для всей студии (для тех, кто не выбрал свой, для страницы входа, писем и выгрузок) задаётся в «Настройки» → «Студия» → «Язык по умолчанию». См. [Настройки](/settings/overview).

## Как устроена документация

Документация повторяет меню приложения. Каждая страница начинается с того, где раздел находится в меню, затем описывает, кому он доступен, и разбирает экран сверху вниз: блоки, колонки, кнопки, диалоги и статусы.

::
