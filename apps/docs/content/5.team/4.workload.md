Раздел «Загрузка команды» показывает, сколько работы назначено каждому сотруднику по сравнению с тем, сколько часов в неделю он может работать. Помогает увидеть перегруженных и свободных людей перед тем, как раздавать новые задачи. Путь в меню: **Команда → Загрузка**, адрес — `/team/workload`.

![Загрузка команды](/screenshots/workload.png)

## Доступ

Нужно право `workload:view`. По умолчанию оно есть у ролей Владелец, Администратор, Продюсер, Менеджер проекта. Права ролей меняются в настройках — см. [Роли и права](/start/roles). Раздел только для просмотра: менять здесь ничего нельзя.

## Как считается загрузка

- В расчёт попадают сотрудники со статусом «Работает» (см. [Сотрудники](/team/employees)).
- **Назначено** — сумма оценок (поле «Оценка, часов» в задаче) всех незакрытых задач сотрудника: в статусах «Бэклог», «Готова к работе», «В работе», «На проверке», «На правках». Задачи без оценки добавляют 0 часов.
- **Норма** — поле «Часов в неделю» из карточки сотрудника.
- **Загрузка, %** = назначено ÷ норма × 100, с округлением. Если нормы нет, загрузка 0%.

::note
Учитываются все открытые задачи сотрудника, а не только те, что со сроком на этой неделе. Чтобы загрузка была точной, у задач должна быть заполнена оценка в часах («Оценка, часов»).
::

## Шапка

Под заголовком — сводка по видимым карточкам, например: «8 чел. · 210ч назначено из 320ч · средняя загрузка 66%». Если есть перегруженные, добавляется красное «· перегружено N». Средняя загрузка — это все назначенные часы, делённые на сумму норм.

## Фильтры

| Фильтр | Что делает |
| --- | --- |
| «Все отделы» | Показывает сотрудников одного отдела |
| «Любая загрузка» | Показывает только сотрудников с выбранным уровнем: «Свободен», «Норма», «Высокая», «Перегружен» |

## Карточка сотрудника

| Элемент | Что показывает |
| --- | --- |
| Имя, должность · отдел | Кто это |
| «40ч из 40ч» | Назначено часов из недельной нормы |
| Значок «100% · Высокая» | Процент загрузки и её уровень (цвет — см. ниже) |
| Полоса | Заполненность недели; при перегрузке полоса заполнена полностью |
| **В работе на неделе** N | Задачи без срока или со сроком в ближайшие 7 дней. Рядом с названием — код проекта. Если таких нет — «Ничего не назначено» |
| **Дальше** N | Задачи со сроком позже чем через 7 дней. Рядом с названием — срок. Если таких нет — «Очередь пуста» |
| «Списано за эту неделю: Nч» | Сколько часов сотрудник записал в [Учёт времени](/team/timesheets) с понедельника текущей недели. Строки нет, если ничего не списано |

В каждом списке показаны первые 5 задач (ближайшие по сроку), а число рядом с заголовком — сколько их всего. Клик по задаче открывает её карточку поверх страницы, подробнее о задачах — [Задачи](/production/tasks).

## Уровни загрузки

| Значок | Цвет | Загрузка |
| --- | --- | --- |
| **Свободен** | зелёный | меньше 60% |
| **Норма** | голубой | от 60% до 84% |
| **Высокая** | жёлтый | от 85% до 99% |
| **Перегружен** | красный | 100% и больше |
