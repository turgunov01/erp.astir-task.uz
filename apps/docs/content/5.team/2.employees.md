Раздел «Сотрудники» — справочник людей студии. Здесь заводят нового сотрудника вместе с его учётной записью для входа, назначают роль и отдел, задают ставку в час и сколько часов в неделю человек может работать. Путь в меню: **Команда → Сотрудники**, адрес — `/team/employees`.

![Список сотрудников](/screenshots/employees.png)

## Доступ

| Действие | Право | По умолчанию есть у |
| --- | --- | --- |
| Открыть список | `team:view` | Владелец, Администратор, Продюсер, Менеджер проекта, Арт-директор |
| Создавать, редактировать, архивировать и удалять сотрудников | `team:manage` | Владелец, Администратор |

Без права `team:manage` кнопки «Новый сотрудник» нет, а меню действий в строке показывает только «Недостаточно прав». Права ролей меняются в настройках — см. [Роли и права](/start/roles).

## Шапка и панель инструментов

Под заголовком — число сотрудников в текущей выборке, например «12 сотрудников».

| Элемент | Что делает | Право |
| --- | --- | --- |
| **Активные** / **Архив** | Переключает список между рабочими записями и архивом. При переключении список открывается с первой страницы | `team:view` |
| :icon{name="i-lucide-plus"} **Новый сотрудник** | Открывает форму создания сотрудника | `team:manage` |
| Поле «Поиск по имени, почте, должности...» | Поиск по имени, фамилии, почте и должности | `team:view` |
| «Все отделы» | Фильтр по отделу | `team:view` |

## Таблица

| Колонка | Что показывает |
| --- | --- |
| **Сотрудник** | Инициалы, имя и фамилия, почта для входа |
| **Должность** | Должность. Если сотруднику назначена роль студии, должностью становится название этой роли |
| **Отдел** | Отдел или прочерк |
| **Роль** | Уровень доступа. Если название роли студии совпадает с должностью, здесь показывается основная роль, на которой она построена (например, «Художник»), чтобы не повторять одно и то же |
| **Часов в неделю** | Сколько часов в неделю сотрудник может работать — от этого считается [Загрузка](/team/workload) |
| **Статус** | Цветной значок статуса (см. ниже) |
| :icon{name="i-lucide-ellipsis"} | Меню действий со строкой |

### Статусы

| Значок | Цвет | Значение |
| --- | --- | --- |
| **Работает** | зелёный | Сотрудник в штате и работает |
| **В отпуске** | жёлтый | Сотрудник в отпуске; в [Посещаемости](/team/attendance) его рабочие дни без прихода считаются отпуском, а не прогулом |
| **Не работает** | серый | Сотрудник больше не работает, либо его учётная запись отключена. Такие сотрудники не попадают в посещаемость |

## Действия со строкой

Меню открывается кнопкой :icon{name="i-lucide-ellipsis"} в последней колонке.

| Кнопка / иконка | Что делает | Право |
| --- | --- | --- |
| :icon{name="i-lucide-pencil"} **Редактировать** | Открывает форму «Редактирование сотрудника» | `team:manage` |
| :icon{name="i-lucide-archive"} **Архивировать** | Сразу убирает сотрудника из рабочего списка в архив, без подтверждения. Обратимо | `team:manage` |
| :icon{name="i-lucide-archive-restore"} **Вернуть из архива** | Возвращает сотрудника в рабочий список (видна в режиме «Архив») | `team:manage` |
| :icon{name="i-lucide-trash-2"} **Удалить** | Удаляет сотрудника после подтверждения | `team:manage` |

## Форма сотрудника

![Форма «Новый сотрудник»](/screenshots/employees-form.png)

Форма открывается сбоку кнопкой **Новый сотрудник** (заголовок «Новый сотрудник») или пунктом **Редактировать** (заголовок «Редактирование сотрудника»). Закрыть — **Отмена**, крестик или :kbd{value="Esc"}.

| Поле | Обязательное | Ограничения и пояснения |
| --- | --- | --- |
| **Имя** | да | До 80 символов |
| **Фамилия** | да | До 80 символов |
| **Почта** | да | Логин для входа, должен быть уникальным. После смены сотрудник подтвердит новую почту кодом при входе |
| **Пароль** | да, только при создании | Минимум 8 символов. Сообщите пароль сотруднику сами |
| **Новый пароль** | нет, только при редактировании | Оставьте пустым, чтобы не менять. При входе сотрудник заменит его на свой |
| **Роль** | да при создании | Список ролей студии из Настроек → «Роли и доступ». Название роли станет должностью сотрудника, права — из настроек роли. При редактировании пустое поле оставляет текущую роль. Если ролей ещё нет, под полем будет ссылка «Настройки → Роли и доступ» |
| **Отдел** | нет | Список из раздела [Отделы](/team/departments) |
| **Занятость** | нет | «Полная занятость», «Частичная занятость», «Фриланс», «Стажировка». По умолчанию — полная занятость |
| **Ставка в час** | нет | От 0 до 100 000. Используется для расчёта себестоимости проектов по списанным часам |
| **Часов в неделю** | нет | Целое число от 1 до 80, по умолчанию 40 |
| **Статус** | нет | «Работает», «В отпуске», «Не работает». По умолчанию — «Работает» |
| **Файлы** | нет | Фото, видео, аудио или документ. Загрузятся сразу после сохранения |

Кнопка внизу — **Создать** для нового сотрудника и **Сохранить** при редактировании.

::note
Месячный оклад в карточке сотрудника не задаётся — он настраивается в разделе [Зарплата](/business/payroll).
::

### Что происходит после создания

- Одновременно создаются карточка сотрудника и его учётная запись — она сразу активна.
- На указанную почту уходит письмо с кодом: при первом входе сотрудник подтверждает почту этим кодом. Подробнее о входе — [Вход и пароль](/start/login).
- Должность берётся из названия выбранной роли.

### Что происходит при смене почты или пароля

- **Новая почта** — сотрудник подтверждает её кодом при следующем входе; на старый адрес приходит письмо о том, что логин изменился.
- **Новый пароль** — сотрудник получает письмо о том, что пароль задан (сам пароль в письме не пересылается), и при следующем входе должен заменить его на свой.
- В обоих случаях все открытые сеансы сотрудника завершаются.

Ограничения:

- свою почту и свой пароль здесь поменять нельзя — пароль меняется в [Профиле](/work/profile);
- менять почту и пароль можно только тем, кто не выше вас по роли: Владелец выше Администратора, Администратор выше остальных ролей;
- нельзя назначить роль, в которой есть права, отсутствующие у вас, или роль на основе роли выше вашей.

## Удаление

После **Удалить** появляется подтверждение «Удалить сотрудника «…»?».

::warning
Учётная запись и доступ удаляются, почта освобождается — её можно сразу использовать для новой учётной записи. Задачи и версии останутся без исполнителя. Если у сотрудника есть записи учёта времени, комментарии или начисления по зарплате, его запись сохраняется в базе без доступа — эти данные не пропадут. Вернуть удалённого сотрудника через интерфейс нельзя; чтобы просто убрать человека из списка, используйте **Архивировать**.
::

Удалить собственную учётную запись нельзя.
