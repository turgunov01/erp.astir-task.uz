Отделы группируют сотрудников по специализации — например, «Анимация», «Композитинг», «Моделинг». По отделу фильтруются списки в разделах [Сотрудники](/team/employees), [Посещаемость](/team/attendance) и [Загрузка](/team/workload). Путь в меню: **Команда → Отделы**, адрес — `/team/departments`.

![Список отделов](/screenshots/departments.png)

Тот же список доступен в Настройках на вкладке «Департаменты» — это один и тот же справочник, изменения видны в обоих местах.

## Доступ

| Действие | Право | По умолчанию есть у |
| --- | --- | --- |
| Открыть список | `team:view` | Владелец, Администратор, Продюсер, Менеджер проекта, Арт-директор |
| Создавать, редактировать, архивировать и удалять отделы | `team:manage` | Владелец, Администратор |

Без права `team:manage` кнопки «Новый отдел» нет, а меню действий в строке показывает только «Недостаточно прав». Подробнее о правах — [Роли и права](/start/roles).

## Панель инструментов

| Элемент | Что делает | Право |
| --- | --- | --- |
| Счётчик, например «5 отделов» | Сколько отделов в текущей выборке | `team:view` |
| **Активные** / **Архив** | Переключает список между рабочими отделами и архивом | `team:view` |
| :icon{name="i-lucide-plus"} **Новый отдел** | Открывает форму создания отдела | `team:manage` |
| Поле «Поиск отдела...» | Поиск по названию | `team:view` |

## Таблица

| Колонка | Что показывает |
| --- | --- |
| **Отдел** | Название |
| **Описание** | Описание или прочерк |
| **Сотрудники** | Сколько сотрудников в отделе |
| :icon{name="i-lucide-ellipsis"} | Меню действий со строкой |

## Действия со строкой

| Кнопка / иконка | Что делает | Право |
| --- | --- | --- |
| :icon{name="i-lucide-pencil"} **Редактировать** | Открывает форму «Редактирование отдела» | `team:manage` |
| :icon{name="i-lucide-archive"} **Архивировать** | Сразу убирает отдел в архив, без подтверждения. Обратимо | `team:manage` |
| :icon{name="i-lucide-archive-restore"} **Вернуть из архива** | Возвращает отдел в рабочий список (видна в режиме «Архив») | `team:manage` |
| :icon{name="i-lucide-trash-2"} **Удалить** | Удаляет отдел после подтверждения | `team:manage` |

## Форма отдела

Форма открывается сбоку кнопкой **Новый отдел** (заголовок «Новый отдел») или пунктом **Редактировать** (заголовок «Редактирование отдела»).

| Поле | Обязательное | Ограничения |
| --- | --- | --- |
| **Название** | да | От 2 до 80 символов |
| **Описание** | нет | До 1000 символов |
| **Файлы** | нет | Фото, видео, аудио или документ. Загрузятся сразу после сохранения |

Кнопка внизу — **Создать** для нового отдела и **Сохранить** при редактировании. Сотрудника переводят в отдел в его форме в разделе [Сотрудники](/team/employees).

## Удаление

После **Удалить** появляется подтверждение «Удалить отдел «…»?».

::warning
Отдел, в котором ещё есть сотрудники, удалить нельзя — система покажет «В отделе ещё есть сотрудники: N. Сначала переведите их в другой отдел.» Удалённый отдел исчезает из списков, вернуть его через интерфейс нельзя. Чтобы просто скрыть отдел, используйте **Архивировать**.
::
