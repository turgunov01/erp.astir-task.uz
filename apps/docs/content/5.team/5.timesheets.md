Раздел «Учёт времени» (табель) — место, где сотрудники списывают рабочие часы на проекты и задачи. Списанные часы формируют фактическую себестоимость проекта: каждый час умножается на ставку сотрудника из его карточки в разделе [Сотрудники](/team/employees). Путь в меню: **Команда → Учёт времени**, адрес — `/timesheets`.

![Учёт времени](/screenshots/timesheets.png)

::note
Учёт времени не связан с [Посещаемостью](/team/attendance): посещаемость считает время на работе по кнопкам смены, а табель — часы, которые сотрудник сам записал на проекты.
::

## Доступ

| Действие | Право | По умолчанию есть у |
| --- | --- | --- |
| Открыть раздел, вкладка «Мои часы» | `timesheet:view:own` | Владелец, Администратор, Продюсер, Менеджер проекта, Арт-директор, Художник |
| Вкладки «Команда», «По проектам», «Отчёт» | `timesheet:view:all` | Владелец, Администратор, Продюсер, Менеджер проекта |
| Списывать часы, удалять записи | `timesheet:submit` | Владелец, Администратор, Продюсер, Менеджер проекта, Арт-директор, Художник |

У роли Финансы по умолчанию есть `timesheet:view:all`, но нет `timesheet:view:own`, поэтому пункт меню у неё не показывается — для доступа к разделу ей нужно выдать и `timesheet:view:own`.

Ограничения по ролям:

- сотрудник с основной ролью **Художник** всегда видит только свои записи и удаляет только свои — даже если ему выдать право `timesheet:view:all`;
- остальные роли с правом `timesheet:submit` могут удалить любую запись, которую видят;
- часы списываются только на себя: учётная запись должна быть привязана к карточке сотрудника, иначе записать часы нельзя.

Права ролей меняются в настройках — см. [Роли и права](/start/roles).

## Шапка

Под заголовком — итог по текущей выборке с учётом фильтров, например «37.5ч за период · 6 записей».

| Кнопка | Что делает | Право |
| --- | --- | --- |
| :icon{name="i-lucide-plus"} **Списать часы** | Раскрывает форму «Новая запись» | `timesheet:submit` |
| :icon{name="i-lucide-x"} **Свернуть** | Сворачивает форму (та же кнопка, пока форма открыта) | `timesheet:submit` |

## Вкладки

| Вкладка | Что показывает |
| --- | --- |
| **Мои часы** | Только ваши записи. Открывается по умолчанию |
| **Команда** | Записи всех сотрудников |
| **По проектам** | Записи всех сотрудников и над таблицей две сводки: «По проектам» и «По сотрудникам» |
| **Отчёт** | То же, что «По проектам»: две сводки и таблица записей |

Выбранная вкладка сохраняется в адресе (`?view=team`, `?view=projects`, `?view=reports`), так что ссылкой можно поделиться. Если у вас нет права на вкладку, по такой ссылке откроются «Мои часы».

### Сводки «По проектам» и «По сотрудникам»

Каждая строка — проект (код · название) или сотрудник, справа сумма часов и в скобках число записей. Строки отсортированы по убыванию часов. Сводки учитывают фильтры по проекту и периоду. Если часов нет — «За период часов нет.»

## Форма «Новая запись»

![Форма «Новая запись»](/screenshots/timesheets-form.png)

| Поле | Обязательное | Ограничения |
| --- | --- | --- |
| **Проект** | да | Выбор из списка проектов. По умолчанию «Не выбран» |
| **Задача** | нет | Только задачи выбранного проекта. По умолчанию «Без задачи» |
| **Дата** | да | По умолчанию — сегодня |
| **Часы** | да | От 0,25 до 24, шаг 0,25 (например, 7.5) |
| **Что делали** | нет | Свободный текст, до 2000 символов |

Кнопка **Записать** сохраняет запись. Если не заполнены проект, дата или часы, появится «Заполните проект, дату и количество часов». После сохранения форма сворачивается, а таблица и итоги обновляются.

## Таблица записей

### Фильтры

| Фильтр | Что делает |
| --- | --- |
| «Все проекты» | Записи одного проекта |
| «Период с» | Записи начиная с этой даты |
| «Период по» | Записи по эту дату включительно |

Поиск по тексту в этом разделе недоступен. Фильтры действуют и на таблицу, и на итог в шапке, и на сводки.

### Колонки

| Колонка | Что показывает |
| --- | --- |
| **Дата** | День, за который списаны часы |
| **Сотрудник** | Имя и должность |
| **Проект** | Название проекта — ссылка на [карточку проекта](/projects/card) |
| **Работа** | Название задачи (клик открывает задачу поверх страницы) и под ним текст «Что делали». Прочерк — нет ни задачи, ни описания |
| **Часы** | Количество часов |
| :icon{name="i-lucide-trash-2"} | Удаление записи (кнопка есть при праве `timesheet:submit`) |

Если записей нет — «Записей нет. Списанные часы формируют фактическую себестоимость проекта.»

## Удаление записи

Кнопка :icon{name="i-lucide-trash-2"} в строке открывает окно «Удаление записи» с вопросом «Удалить 4ч за …?». Подтвердите кнопкой **Удалить**.

::warning
Удаление необратимо: часы исчезнут из отчётов и себестоимости проекта.
::

Отредактировать уже сохранённую запись в интерфейсе нельзя — удалите её и спишите часы заново.

Сводные отчёты по времени и людям — в разделе [Отчёты → Время](/reports/time).
