Раздел «Таймлайн» раскладывает задачи с датами на временной шкале: можно увидеть, что идёт сейчас, что просрочено, какие задачи зависят друг от друга и когда наступают вехи проектов. Путь в меню: **Команда → Таймлайн**, адрес — `/timeline`.

![Таймлайн: вид «Гант»](/screenshots/timeline.png)

## Доступ

Нужно право `production:view`. По умолчанию оно есть у ролей Владелец, Администратор, Продюсер, Менеджер проекта, Арт-директор, Художник. Права ролей меняются в настройках — см. [Роли и права](/start/roles).

- Кто видит все задачи (право `task:view` — по умолчанию все перечисленные роли, кроме Художника), видит на шкале задачи всех исполнителей.
- Без права `task:view` (по умолчанию Художник) на шкале только свои задачи.

Раздел только для просмотра. Изменить задачу можно в её карточке, которая открывается кликом по задаче; после сохранения шкала обновляется сама.

## Что попадает на шкалу

- Задача занимает отрезок от даты начала до срока. Если задана только одна из дат, задача стоит в этот день.
- Задачи без даты начала и без срока на шкалу не попадают — под шкалой пишется «Без дат и потому не на шкале: N задач».
- Показывается не больше 1000 задач. Если их больше, под шкалой появится красное «Показаны первые 1000 задач — сузьте период или выберите проект».
- **Просроченная** задача — у которой срок уже прошёл, а статус не «Утверждена» и не «Завершена».

## Шапка

Под заголовком — выбранный проект (или «Все проекты») и сколько задач на шкале. Справа переключатель вида:

| Кнопка | Вид |
| --- | --- |
| :icon{name="i-lucide-chart-gantt"} **Гант** | Диаграмма Ганта (открывается по умолчанию) |
| :icon{name="i-lucide-list"} **Лента** | Задачи и вехи списком по неделям |
| :icon{name="i-lucide-chart-column-stacked"} **Графики** | Сводные графики по статусам и срокам |

## Панель настроек

| Элемент | Что делает |
| --- | --- |
| «Все проекты» | Ограничить шкалу одним проектом |
| «Все исполнители» | Показать задачи одного исполнителя |
| «с» / «по» | Период: на шкалу попадают задачи, отрезок которых пересекается с периодом. Если период задан, ось Ганта начинается и заканчивается на его границах |
| **Только просроченные** | Оставить только просроченные задачи. Рядом красным — сколько их |
| :icon{name="i-lucide-x"} **Сбросить** | Снять все фильтры (появляется, когда хоть один фильтр задан) |
| Кнопки статусов | «Бэклог», «Готова к работе», «В работе», «На проверке», «На правках», «Утверждена», «Завершена», «Заблокирована». Нажатая кнопка добавляет статус в фильтр; можно выбрать несколько. Ни одна не нажата — показываются все статусы |
| «Группировка» | «По проектам», «По этапам», «По исполнителям», «По статусам». Для одного проекта по умолчанию — по этапам, для всех проектов — по проектам. В виде «Лента» не показывается |
| «Масштаб» | «Дни», «Недели», «Месяцы» — только в виде «Гант». Пока масштаб не выбран, он подбирается сам по длине периода: до 45 дней — дни, до 240 дней — недели, дальше — месяцы |

Все настройки сохраняются в адресе страницы: настроенный вид — например, «Гант проекта по исполнителям, в неделях, только на проверке» — можно добавить в закладки или отправить коллеге.

## Цвета статусов

Один цвет означает один статус во всех трёх видах.

| Статус | Цвет |
| --- | --- |
| Бэклог | серый |
| Готова к работе | голубой |
| В работе | фиолетовый |
| На проверке | жёлтый |
| На правках | оранжевый |
| Утверждена | бирюзовый |
| Завершена | зелёный |
| Заблокирована | тёмно-красный |

## Вид «Гант»

Слева колонка **Задача** с названиями (просроченные — красным), справа — полосы на шкале. При открытии шкала прокручивается к сегодняшнему дню.

- **Красная вертикаль** — сегодня.
- **Полоса** — задача, цвет по статусу. Короткие полосы подписаны справа.
- **Красная обводка и пунктирный хвост** — просроченная задача; хвост тянется от срока до сегодняшнего дня.
- **Стрелки** — зависимости между задачами. Красный пунктир — задача начинается раньше, чем закончится та, от которой она зависит.
- **Строка «Вехи»** :icon{name="i-lucide-flag"} — ромбы вех проектов на их датах. Если хватает места, рядом подписано название; полное название и дата — во всплывающей подсказке.
- **Строки групп** — заголовок группы с числом задач и красным числом просроченных. Клик по заголовку :icon{name="i-lucide-chevron-down"} сворачивает или разворачивает группу. При группировке по проектам рядом есть :icon{name="i-lucide-arrow-up-right"} «Открыть проект» — переход в [карточку проекта](/projects/card).

Клик по названию задачи или по её полосе открывает карточку задачи поверх страницы. Подробнее о задачах — [Задачи](/production/tasks).

## Вид «Лента»

![Таймлайн: вид «Лента»](/screenshots/timeline-line.png)

Задачи и вехи идут одной вертикальной лентой, сгруппированные по неделям. Задача стоит в неделе своего срока, а если срока нет — в неделе даты начала. Текущая неделя отмечена красной точкой и подписью «эта неделя», прошедшие недели — серой точкой.

- **Задача** — цветная точка статуса, название, под ним код проекта · этап · исполнитель, справа даты и значок статуса. У просроченной задачи вместо статуса красный значок «Просрочена». Клик открывает карточку задачи.
- **Веха** — ромб, название, код проекта и дата. Ромб зелёный, если веха выполнена, красный — если её дата прошла, а она не выполнена, фиолетовый — если ещё впереди.

## Вид «Графики»

![Таймлайн: вид «Графики»](/screenshots/timeline-charts.png)

Плитки сверху:

| Плитка | Что показывает |
| --- | --- |
| **Задач на шкале** | Сколько задач попало на шкалу |
| **В работе** | Задачи в статусах «В работе», «На проверке», «На правках» |
| **Просрочено** | Просроченные задачи; рядом — сколько заблокировано («N заблок.») |
| **Готово** | Доля задач в статусах «Утверждена» и «Завершена», в процентах |

Под плитками — легенда статусов с числами. Клик по статусу в легенде оставляет на шкале только его.

- **Статусы по проектам** (по этапам, по исполнителям, по статусам — смотря по группировке) — по полосе на каждую группу: длина полосы — объём задач, цветные сегменты — в каком они состоянии. Справа — число задач и красным «N просроч.».
- **Сроки по неделям** (или **Сроки по месяцам**, если сроки растянуты больше чем на полгода) — сколько задач должно закрыться в каждый период и в каком они статусе сейчас. Красное число — уже просрочено. Если ни у одной задачи нет срока — «Ни у одной задачи нет срока.»

## Пустые состояния

| Сообщение | Что значит |
| --- | --- |
| «Ни одного проекта ещё нет — размещать на шкале нечего.» со ссылкой **Создать проект** | В студии нет проектов, см. [Создание и редактирование проекта](/projects/create) |
| «Под эти фильтры не попала ни одна задача с датами.» со ссылкой **Сбросить фильтры** | Фильтры отсекли все задачи |
| «У задач пока нет ни дат начала, ни сроков — разместить их на шкале не на чем.» | Задачи есть, но ни у одной нет дат |
