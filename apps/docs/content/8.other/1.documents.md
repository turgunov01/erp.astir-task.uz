Документы — общая библиотека всех файлов, прикреплённых в системе. Пункт **«Документы»** находится в нижней части бокового меню, адрес — `/documents`. Заголовок страницы — «Документы и медиа».

Файлы попадают сюда сами: из вложений в формах и карточках (проекты, клиенты, эпизоды, сцены, шоты, задачи, правки, ассеты, рендер, согласования, отделы, сотрудники) и из файлов, приложенных при смене статуса задачи. Файл, прикреплённый к записи проекта, автоматически относится и к этому проекту.

![Документы](/screenshots/documents.png)

## Доступ

| Действие | Право | По умолчанию есть у |
|---|---|---|
| Смотреть библиотеку | `document:view` | Владелец, Администратор, Продюсер, Менеджер проекта, Клиент, Финансы |
| Редактировать, архивировать, удалять | `document:manage` | Владелец, Администратор, Финансы |

У Арт-директора и Художника права `document:view` по умолчанию нет — пункта «Документы» в их меню нет.

Без права `document:manage` в меню действий строки вместо пунктов написано «Недостаточно прав».

## Шапка страницы

- Под заголовком — общее число файлов (с учётом фильтров) и сколько медиафайлов на текущей странице: например, «48 файлов · 6 медиа на странице».
- Кнопка :icon{name="i-lucide-images"} «Посмотреть галерею» появляется, если на текущей странице больше одного медиафайла (картинки, видео, звук). Она открывает просмотрщик, в котором можно листать только медиа этой страницы.

## Активные и архив

Переключатель «Активные» / «Архив» над таблицей. «Активные» — рабочий набор файлов, «Архив» — файлы, которые убрали в архив. При переключении список начинается с первой страницы.

## Фильтры и поиск

| Элемент | Что делает |
|---|---|
| Поле «Поиск по названию файла...» | Ищет по названию файла без учёта регистра |
| Список «Все проекты» | Оставляет файлы одного проекта |
| Флажок «Только медиа» | Оставляет только картинки, видео и звук |

Файлы отсортированы по дате загрузки — новые сверху, по 25 на странице.

## Таблица

| Колонка | Что показывает |
|---|---|
| «Файл» | Миниатюра и название. Нажатие открывает файл в просмотрщике; стрелками в нём можно листать остальные файлы этой страницы. |
| «Задача» | Задача, к которой прикреплён файл. Нажатие открывает панель задачи. Если файл не прикреплён к задаче — «не привязан». |
| «Проект» | Проект файла — ссылка на [карточку проекта](/projects/card). |
| «Тип» | Тип документа: «Договор», «Бриф», «Спецификация», «Счёт», «Акт», «NDA» или «Прочее». |
| «Размер» | Размер файла. |
| «Загрузил» | Имя того, кто загрузил файл. |
| :icon{name="i-lucide-ellipsis"} | Меню действий строки. |

Если файлов нет — «Файлов пока нет» и подсказка «Прикрепите файлы к задаче или проекту — они появятся здесь.».

## Действия со строкой

| Кнопка / иконка | Что делает | Право |
|---|---|---|
| :icon{name="i-lucide-images"} «Посмотреть галерею» | Открывает просмотр медиафайлов текущей страницы | `document:view` |
| «Активные» / «Архив» | Переключают рабочий набор и архив | `document:view` |
| :icon{name="i-lucide-ellipsis"} | Открывает меню действий строки | `document:view` |
| :icon{name="i-lucide-pencil"} «Редактировать» | Открывает форму «Редактирование документа» | `document:manage` |
| :icon{name="i-lucide-archive"} «Архивировать» | Убирает файл в архив | `document:manage` |
| :icon{name="i-lucide-archive-restore"} «Вернуть из архива» | Возвращает файл из архива (в режиме «Архив») | `document:manage` |
| :icon{name="i-lucide-trash-2"} «Удалить» | Удаляет файл после подтверждения | `document:manage` |

## Редактирование документа

Форма «Редактирование документа» меняет только описание файла — сам файл остаётся прежним.

| Поле | Обязательное | Ограничения |
|---|---|---|
| «Название» | да | до 200 символов |
| «Тип» | да | один из типов документа |
| «Проект» | нет | можно очистить |
| «Клиент» | нет | можно очистить |

После сохранения изменение записывается в [Ленту событий](/other/activity).

## Архив и удаление

- **Архивирование** обратимо: файл пропадает из списка «Активные», его можно найти в «Архиве» и вернуть кнопкой «Вернуть из архива».
- **Удаление** спрашивает подтверждение «Удалить документ «…»?».

::warning
Удаление необратимо: файл исчезает из всех списков, а сам файл стирается из хранилища. Вернуть его через интерфейс нельзя. Если файл может ещё понадобиться, используйте архивирование.
::
