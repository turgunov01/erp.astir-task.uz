Лента событий — журнал действий в студии: кто что создал, назначил, изменил и перевёл в другой статус. Пункт **«Лента событий»** находится в нижней части бокового меню, адрес — `/activity`.

Лента только читается: исправить или удалить событие нельзя — в этом её смысл.

![Лента событий](/screenshots/activity.png)

## Доступ

Нужно право `activity:view` (по умолчанию есть у: Владелец, Администратор, Продюсер, Менеджер проекта, Арт-директор, Финансы). У Художника и Клиента этого права нет.

События о задачах видны по тому же правилу, что и сами задачи. С правом `task:view` (по умолчанию: Владелец, Администратор, Продюсер, Менеджер проекта, Арт-директор) видны события обо всех задачах. Без него (по умолчанию — Финансы) видны только события о задачах, назначенных на вас; события о других объектах видны полностью.

Восемь последних событий также показываются на [Панели управления](/work/dashboard) в блоке «Последние события».

## Какие события попадают в ленту

Событие записывается, когда кто-то меняет данные в системе. Основные группы:

| Группа | Примеры событий |
|---|---|
| Проекты | создал проект, сменил статус проекта, архивировал проект, удалил проект без возврата |
| Команды проектов | добавил участника в проект, убрал участника из проекта |
| Этапы, эпизоды, сцены, шоты | создание и смена статуса; смена статуса этапа шота |
| Задачи | создал задачу, назначил исполнителя, сменил статус задачи, архивировал задачу, вернул задачу из архива, удалил задачу |
| Версии | загрузил версию, отправил версию на согласование, удалил версию |
| Согласование | утвердил версию, запросил правки по версии, отклонил версию |
| Правки | завёл правку, сменил статус правки, удалил правку |
| Рендер, ассеты, файлы | поставил задачу в очередь рендера, добавил ассет, загрузил файл |
| Финансы | бюджеты, расходы, счета, платежи и записи зарплаты — создание, изменение, удаление |
| Клиенты, отделы, сотрудники, пользователи | создание, изменение, архивирование; смена роли; отключение пользователя; смена почты и пароля сотрудника |
| Посещаемость | начал смену, поставил смену на паузу, продолжил смену, закончил смену |
| Настройки | изменил настройки студии, работа с шаблонами пайплайна, проверка почтовых настроек |

Действие, для которого в интерфейсе нет подписи, показывается как «выполнил действие».

## Фильтры

Фильтры стоят под заголовком. Все они сохраняются в адресе страницы, поэтому отфильтрованную ленту можно открыть по ссылке — например, отправить коллеге «что было с этим проектом во вторник». При изменении любого фильтра лента возвращается на первую страницу.

| Фильтр | Что делает |
|---|---|
| «Все проекты» | Оставляет события одного проекта. В списке — код и название проекта. |
| «Все авторы» | Оставляет события одного сотрудника. |
| «Любые события» | Оставляет одну группу событий: «Задачи», «Проекты», «Финансы» и т. д. В скобках — сколько таких событий в журнале. В списке только группы, которые реально встречаются. |
| «Любые объекты» | Оставляет события об одном типе объекта: «Проект», «Задача», «Шот», «Документ» и т. д. В скобках — число событий. |
| «С» и «по» | Период по датам. Дата «по» включает весь день целиком. |

Кнопка «Сбросить» появляется, когда задан хотя бы один фильтр, и снимает все фильтры сразу.

## Лента

Над лентой — общее число найденных событий: «Событий: N». События идут от новых к старым и сгруппированы по дням: над каждой группой — дата.

Каждая строка события:

- **Кто и что сделал**: имя автора (или «Система», если действие выполнено автоматически) и действие, например «Анна Иванова сменил статус задачи».
- **Подробности** (если есть): название объекта в кавычках и смена статуса в виде «Было → Стало».
- **Строка под событием**: тип объекта (например, «Задача»), ссылка на проект и ссылка «Открыть». «Открыть» ведёт в карточку проекта или шота, если событие о них, а для остальных событий — в карточку проекта, к которому событие относится.
- **Время справа** — сколько прошло с момента события. При наведении видны точные дата и время.

На странице 30 событий. Внизу — кнопки «Назад» и «Дальше» и подпись «Страница N из M».

## Кнопки

| Кнопка / иконка | Что делает | Право |
|---|---|---|
| Фильтры «Все проекты», «Все авторы», «Любые события», «Любые объекты», «С», «по» | Сужают ленту | `activity:view` |
| «Сбросить» | Снимает все фильтры | `activity:view` |
| «Сбросить фильтры» | То же, в пустом результате | `activity:view` |
| Название проекта | Открывает карточку проекта | `project:view` |
| «Открыть» | Открывает объект события или его проект | право на целевую страницу |
| «Назад» / «Дальше» | Листают страницы ленты | `activity:view` |
| «Повторить» | Повторно загружает ленту после ошибки | `activity:view` |

## Пустая лента

- Без фильтров: «Пока нет событий» — «Здесь появятся изменения статусов, версии и согласования — как только они произойдут.»
- С фильтрами: «Под эти фильтры ничего не подошло» — «Попробуйте расширить период или снять часть фильтров.» и кнопка «Сбросить фильтры».
