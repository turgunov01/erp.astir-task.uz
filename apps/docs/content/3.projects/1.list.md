Раздел «Проекты» — портфель студии: все проекты с клиентом, статусом, прогрессом, сроком и уровнем риска. Отсюда открывается [карточка проекта](/projects/card) и [форма создания](/projects/create).

Где в меню: пункт **«Проекты»** в боковом меню, адрес `/projects`.

![Список проектов](/screenshots/projects.png)

## Доступ

| Что можно | Право | По умолчанию есть у |
|---|---|---|
| Открыть раздел и видеть список | `project:view` | все роли: Владелец, Администратор, Продюсер, Менеджер проекта, Арт-директор, Художник, Клиент, Финансы |
| Создать проект (кнопка «Новый проект») | `project:create` | Владелец, Администратор, Продюсер |
| Видеть действия в меню строки и редактировать проект | `project:update` | Владелец, Администратор, Продюсер, Менеджер проекта |
| Архивировать, возвращать из архива и удалять проект | `project:archive` | Владелец, Администратор, Продюсер |

Права ролей студия может менять в настройках (кроме Владельца) — подробнее в разделе [Роли и права](/start/roles).

- Пользователь с ролью **Клиент** видит в списке только проекты своего клиента.
- Без права `project:create` кнопки «Новый проект» нет.
- Без права `project:update` в меню строки вместо действий написано «Недостаточно прав».
- Меню строки показывается всем, у кого есть `project:update`, но архивирование и удаление сервер выполняет только при праве `project:archive`. Например, Менеджер проекта по умолчанию увидит эти пункты, но получит сообщение о нехватке прав.

## Шапка страницы

- Над заголовком — подпись «Портфель», заголовок — «Проекты».
- Под заголовком — сколько проектов в текущей выборке, например «12 проектов в системе».
- Справа — переключатель **«Активные» / «Архив»** и кнопка **«Новый проект»**.

Переключатель выбирает, что показывает таблица: рабочий список или архив. При переключении таблица возвращается на первую страницу.

## Поиск и фильтр

- Строка поиска «Поиск по названию или коду...» ищет по названию и коду проекта без учёта регистра.
- Выпадающий список **«Все статусы»** оставляет в таблице проекты с одним выбранным статусом (список статусов — ниже).

Поиск, фильтр статуса и номер страницы сохраняются в адресе страницы, поэтому отфильтрованный список можно отправить коллеге ссылкой. Таблица показывает по 20 проектов на странице.

## Таблица проектов

| Колонка | Что показывает |
|---|---|
| «Код» | Код проекта вида `AST-001`; щелчок открывает карточку проекта |
| «Проект» | Название (щелчок открывает карточку), под ним — число шотов и задач |
| «Клиент» | Клиент проекта или «—» |
| «Статус» | Цветной значок статуса проекта |
| «Прогресс» | Полоса и процент готовности проекта |
| «Срок» | Дедлайн проекта. Красным — если срок прошёл, а прогресс меньше 100% |
| «Риск» | Цветной значок уровня риска |
| (последняя) | Кнопка :icon{name="i-lucide-ellipsis"} — меню действий со строкой |

Если проектов ещё нет, таблица показывает «Пока нет проектов» и подсказку «Создайте первый проект, чтобы начать отслеживать производство.»

### Прогресс и риск

Прогресс вручную не вводится: он считается по стадиям пайплайна проекта с учётом их веса (вкладка «Пайплайн» в [карточке проекта](/projects/card)). Завершённая стадия считается как 100%.

Риск тоже считается автоматически — по тому, насколько готовность отстаёт от прошедшей части срока между датой начала и дедлайном, и по числу просроченных задач:

| Значок | Цвет | Когда ставится |
|---|---|---|
| «Низкий» | зелёный | Отставания нет или оно меньше 10 процентных пунктов |
| «Средний» | синий | Готовность отстаёт от прошедшего времени на 10–19 пунктов |
| «Высокий» | жёлтый | Отставание 20–34 пункта или 5 и больше просроченных задач |
| «Критический» | красный | Отставание 35 пунктов и больше, дедлайн прошёл при незавершённом проекте или 12 и больше просроченных задач |

Отставание по времени учитывается, только если у проекта заданы и дата начала, и дедлайн. Полоса прогресса окрашивается по риску: красная при критическом, жёлтая при высоком, в остальных случаях — основного цвета.

### Статусы проекта

| Значок | Цвет | Что означает |
|---|---|---|
| «Черновик» | серый | Проект заведён, работа ещё не начата (статус по умолчанию для нового проекта) |
| «Планирование» | синий | Идёт планирование |
| «Препродакшен» | синий | Подготовка к производству |
| «Продакшен» | фиолетовый | Идёт производство |
| «Постпродакшен» | фиолетовый | Идёт постпродакшен |
| «У клиента» | жёлтый | Материал на просмотре у клиента |
| «Сдача» | жёлтый | Идёт сдача проекта |
| «Завершён» | зелёный | Проект завершён |
| «Приостановлен» | жёлтый | Работа поставлена на паузу |
| «Отменён» | красный | Проект отменён |
| «В архиве» | серый | Проект помечен архивным. Этот же статус ставится при удалении проекта |

Статус меняется вручную в [форме редактирования проекта](/projects/create).

## Кнопки и действия

| Кнопка / иконка | Что делает | Право |
|---|---|---|
| «Активные» / «Архив» | Переключает таблицу между рабочим списком и архивом | `project:view` |
| :icon{name="i-lucide-plus"} «Новый проект» | Открывает страницу создания проекта `/projects/create` | `project:create` |
| :icon{name="i-lucide-ellipsis"} | Открывает меню действий со строкой | `project:view` |
| :icon{name="i-lucide-pencil"} «Редактировать» | Открывает страницу редактирования проекта (только в виде «Активные») | `project:update` |
| :icon{name="i-lucide-archive"} «Архивировать» | Переносит проект в архив (только в виде «Активные») | `project:archive` |
| :icon{name="i-lucide-archive-restore"} «Вернуть из архива» | Возвращает проект в рабочий список (только в виде «Архив») | `project:archive` |
| :icon{name="i-lucide-trash-2"} «Удалить» | Спрашивает подтверждение и убирает проект из списков | `project:archive` |

## Архив и удаление

**Архивирование** обратимо. Проект пропадает из вида «Активные» и появляется в виде «Архив»; все данные остаются на месте. Чтобы вернуть проект, переключитесь на «Архив», откройте меню строки и выберите «Вернуть из архива».

**Удаление** из меню строки сначала показывает окно «Удаление» с вопросом «Удалить проект «…»?» и кнопками «Удалить» и «Отмена». После подтверждения проект получает статус «В архиве» и пропадает и из «Активных», и из «Архива»; его карточка больше не открывается.

::warning
Удалённый из списка проект через интерфейс не вернуть. Если проект просто больше не нужен в работе, используйте «Архивировать».
::

Полное безвозвратное удаление проекта со всеми эпизодами, шотами, задачами, файлами и финансами выполняется отдельно — в «Опасной зоне» на странице [редактирования проекта](/projects/create), и доступно только Владельцу.
