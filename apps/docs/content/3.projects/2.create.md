Проект создаётся на отдельной странице `/projects/create`, а редактируется на странице `/projects/<id>/edit`.

Как открыть:

- **Создание** — кнопка **«Новый проект»** в правом верхнем углу [списка проектов](/projects/list).
- **Редактирование** — кнопка **«Редактировать»** в шапке [карточки проекта](/projects/card) или пункт «Редактировать» в меню :icon{name="i-lucide-ellipsis"} строки списка проектов.

![Форма нового проекта](/screenshots/project-create.png)

## Доступ

| Что можно | Право | По умолчанию есть у |
|---|---|---|
| Создать проект | `project:create` | Владелец, Администратор, Продюсер |
| Редактировать проект | `project:update` | Владелец, Администратор, Продюсер, Менеджер проекта |
| Архивировать проект из «Опасной зоны» | `project:archive` | Владелец, Администратор, Продюсер |
| Удалить проект безвозвратно | `project:delete` | только Владелец |

Права ролей студия может менять в настройках (кроме Владельца) — подробнее в разделе [Роли и права](/start/roles).

Без нужного права страница не открывается: вместо формы появляется ошибка «Нет прав на создание проектов» или «Нет прав на изменение проекта».

## Создание проекта

Вверху страницы — ссылка :icon{name="i-lucide-arrow-left"} «К проектам», заголовок «Новый проект» и пояснение: код вида `AST-001` присваивается автоматически, а шаблон разворачивает пайплайн вместе с созданием проекта.

Форма состоит из двух блоков.

### Блок «Основное»

Название, клиент и ответственные за проект.

| Поле | Обязательное | Что вводить |
|---|---|---|
| «Название» | да | От 2 до 200 символов, например «Анимационный сериал — эпизод 01» |
| «Клиент» | да | Выберите клиента из списка («Выберите клиента»). Клиента заводят заранее в разделе [Клиенты](/business/clients) |
| «Менеджер проекта» | нет | Сотрудник с ролью Владелец, Администратор, Продюсер или Менеджер проекта. По умолчанию — «Не назначен» |
| «Тип» | да | Вид работы: «2D-анимация», «3D-анимация» (по умолчанию), «Моушн-дизайн», «Реклама», «Короткий метр», «Сериал», «Полный метр», «Прочее» |
| «Статус» | да | Статус проекта, по умолчанию «Черновик». Все статусы описаны в разделе [Проекты](/projects/list) |
| «Приоритет» | да | «Низкий», «Обычный» (по умолчанию), «Высокий», «Срочный» |

### Блок «Сроки и бюджет»

Даты определяют расчёт риска, шаблон — состав пайплайна.

| Поле | Обязательное | Что вводить |
|---|---|---|
| «Дата начала» | нет | Дата старта работ |
| «Дедлайн» | нет | Срок сдачи. Не может быть раньше даты начала — иначе появится ошибка «Дедлайн не может быть раньше даты старта» |
| «Бюджет» | нет | Сумма от 0 до 1 000 000 000 |
| «Валюта» | да | Трёхбуквенный код валюты, по умолчанию `USD` |
| «Шаблон пайплайна» | нет | Набор стадий, которые появятся в проекте. По умолчанию — «3D-анимация». «Без шаблона» — проект создаётся с пустым пайплайном |

::tip
Риск проекта по отставанию от графика считается, только когда заданы и «Дата начала», и «Дедлайн». Заполните обе даты, чтобы значок риска был осмысленным.
::

Если студия изменила состав шаблона в настройках, проект получит стадии из изменённого шаблона. У каждой стадии есть вес: он определяет, насколько стадия влияет на прогресс проекта.

### Кнопки формы создания

| Кнопка / иконка | Что делает |
|---|---|
| :icon{name="i-lucide-arrow-left"} «К проектам» | Возвращает к списку без сохранения |
| «Создать проект» | Создаёт проект. Пока идёт сохранение, на кнопке написано «Создание...» |
| «Отмена» | Возвращает к списку без сохранения |

### Что происходит после создания

- Проекту присваивается следующий свободный код вида `AST-001`, `AST-002`…
- Если выбран шаблон, в проекте сразу появляются его стадии пайплайна.
- У проекта появляется бюджет: сумма из поля «Бюджет» записывается в него как плановая выручка (см. [Бюджеты](/business/budgets)).
- Выбранный менеджер проекта получает уведомление «Новый проект».
- Открывается [карточка нового проекта](/projects/card).

Если сохранить не удалось, над формой появляется сообщение об ошибке, а под проблемным полем — пояснение.

::note
Поле «Описание» на странице создания отсутствует — описание добавляется потом, при редактировании проекта.
::

## Редактирование проекта

Вверху — ссылка :icon{name="i-lucide-arrow-left"} «К проекту», код проекта, заголовок «Редактирование проекта» и пояснение: код проекта не меняется, а прогресс и риск считаются автоматически.

Форма та же, что при создании, с такими отличиями:

- в блоке «Основное» есть поле **«Описание»** (до 4000 символов) — оно показывается на вкладке «Обзор» карточки проекта;
- у поля «Клиент» нет пустого варианта — клиента можно сменить, но не убрать;
- поля «Шаблон пайплайна» нет: стадии уже созданы, их меняют на вкладке «Пайплайн» карточки проекта;
- очищенные поля «Менеджер проекта», «Дата начала», «Дедлайн» и «Бюджет» сохраняются пустыми.

| Кнопка / иконка | Что делает |
|---|---|
| :icon{name="i-lucide-arrow-left"} «К проекту» | Возвращает в карточку без сохранения |
| «Сохранить» | Сохраняет изменения и открывает карточку проекта. Во время сохранения — «Сохранение...» |
| «Отмена» | Возвращает в карточку без сохранения |

Если назначен новый менеджер проекта, он получает уведомление «Новый проект». Смена статуса записывается в [ленту событий](/other/activity).

## Опасная зона

Под формой редактирования — блок **«Опасная зона»** с пояснением «Действия ниже влияют на весь проект и его данные.» Блок виден, только если есть право `project:archive` или `project:delete`; каждая строка блока — только при своём праве.

| Кнопка / иконка | Что делает | Право |
|---|---|---|
| :icon{name="i-lucide-archive"} «Архивировать» | Убирает проект из списков и возвращает к списку проектов. Пока идёт запрос — «Архивация...» | `project:archive` |
| :icon{name="i-lucide-trash-2"} «Удалить» | Открывает подтверждение безвозвратного удаления | `project:delete` |
| «Удалить «…» навсегда» | Удаляет проект безвозвратно. Активна только после ввода кода проекта | `project:delete` |
| «Отмена» | Закрывает подтверждение удаления и очищает поле кода | `project:delete` |

### Архивировать проект

Кнопка «Архивировать» неактивна, если в поле «Статус» формы выбрано «В архиве» — тогда строка называется «Проект в архиве».

::warning
Несмотря на подсказку в блоке, после нажатия «Архивировать» здесь проект пропадает и из вида «Активные», и из вида «Архив» списка проектов, а его карточка больше не открывается. Вернуть его через интерфейс нельзя. Для обратимого скрытия используйте пункт «Архивировать» в меню строки [списка проектов](/projects/list).
::

### Удалить безвозвратно

1. Нажмите :icon{name="i-lucide-trash-2"} «Удалить» в строке «Удалить безвозвратно».
2. Введите код проекта в поле «Введите код проекта … для подтверждения» (регистр не важен).
3. Нажмите «Удалить «название проекта» навсегда». Пока идёт удаление — «Удаление...».

После удаления открывается список проектов.

::caution
Будут стёрты эпизоды, сцены, шоты, задачи, версии, стадии пайплайна, бюджет, платежи, счета, документы и загруженные файлы проекта. Восстановить их нельзя. Сервер ещё раз сверяет введённый код и откажет, если он не совпадает.
::
