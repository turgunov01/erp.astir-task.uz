«Расходы» — журнал всех трат студии. Расход с проектом входит в фактическую себестоимость этого проекта (см. [Бюджеты](/business/budgets)); расход без проекта — в накладные студии (аренда, налоги, подписки).

Где в меню: **«Финансы» → «Расходы»**, адрес `/finance/expenses`.

![Журнал расходов](/screenshots/expenses.png)

## Доступ

| Что можно | Право | По умолчанию есть у |
|---|---|---|
| Открыть страницу, фильтровать, выгружать CSV | `finance:view` | Владелец, Администратор, Финансы |
| Добавлять, редактировать и удалять расходы | `finance:manage` | Владелец, Администратор, Финансы |

Права ролей студия может менять в настройках (кроме Владельца) — см. [Роли и права](/start/roles). Без права `finance:manage` кнопки «Новый расход» нет, а в меню строки написано «Недостаточно прав».

## Шапка страницы

- Заголовок «Расходы», под ним — число записей и выбранный период, например «12 записей · всё время».
- Справа — кнопка :icon{name="i-lucide-download"} **«CSV»** и кнопка **«Новый расход»**.

## Период и фильтры

Выбор периода: «Всё время» / «Месяц» / «Квартал» / «Год» / «Период», стрелки :icon{name="i-lucide-chevron-left"} :icon{name="i-lucide-chevron-right"} для листания и поля «с» / «по» для произвольного диапазона. По умолчанию — «Всё время». Расход попадает в период по своей дате.

| Фильтр | Варианты |
|---|---|
| Проект | «Все проекты», «Студия — без проекта» или конкретный проект |
| Клиент | «Все клиенты» или клиент — показывает расходы проектов этого клиента |
| Категория | «Все категории» или одна из категорий (см. ниже) |
| Способ оплаты | «Любой способ», «Перечисление», «Наличные», «Карта», «Другое» |
| Валюта | «Все валюты», `USD`, `UZS`, `EUR`, `RUB` и другие валюты, встречающиеся в итогах |

Если выбран хотя бы один фильтр, появляется кнопка **«Сбросить»**. Фильтры и период сохраняются в адресе страницы.

Поиск над таблицей — «Контрагент, описание, № документа»: ищет по описанию, контрагенту и номеру документа.

## Таблица расходов

По 20 записей на странице.

| Колонка | Что показывает |
|---|---|
| «Дата» | Дата расхода |
| «Проект» | Проект (ссылка на карточку) и клиент под ним. Для расхода без проекта — «Студия» |
| «Категория» | Категория расхода, под ней — способ оплаты |
| «Контрагент и описание» | Кому заплатили (жирным) и описание |
| «Документ» | Номер документа. Если указана ссылка на скан — номер (или слово «Скан») становится ссылкой :icon{name="i-lucide-external-link"}, открывается в новой вкладке |
| «Сумма» | Сумма в валюте расхода, под ней — «НДС …», если указан |
| «Внёс» | Кто добавил запись |
| (последняя) | :icon{name="i-lucide-ellipsis"} — меню действий |

Если под фильтр ничего не попало — «Под фильтр ничего не попало»; если расходов ещё нет — «Пока нет расходов».

### Итоги

Под таблицей — итоги по каждой валюте: «Итого USD · N зап.», «Расходы» и «в т.ч. НДС» (НДС показывается, только если он не нулевой). Итоги считаются по всем записям под фильтром, а не только по текущей странице.

### Категории расходов

«Штат», «Подряд», «Рендер», «Софт», «Железо», «Звук», «Продакшн», «Аренда и офис», «Налоги и сборы», «Маркетинг», «Прочее».

## Кнопки и действия

| Кнопка / иконка | Что делает | Право |
|---|---|---|
| :icon{name="i-lucide-download"} «CSV» | Скачивает расходы под текущими фильтрами и периодом в CSV (не более 5000 строк) | `finance:view` |
| :icon{name="i-lucide-plus"} «Новый расход» | Открывает форму «Новый расход» | `finance:manage` |
| «Сбросить» | Сбрасывает фильтры | `finance:view` |
| :icon{name="i-lucide-ellipsis"} | Меню действий со строкой | `finance:view` |
| :icon{name="i-lucide-pencil"} «Редактировать» | Открывает форму «Редактирование расхода» | `finance:manage` |
| :icon{name="i-lucide-trash-2"} «Удалить» | Спрашивает подтверждение и удаляет расход | `finance:manage` |

::warning
Удаление расхода необратимо: запись исчезнет из списков и из фактической себестоимости проекта. Архива у расходов нет.
::

## Форма расхода

Боковая панель «Новый расход» / «Редактирование расхода», кнопки «Отмена» и «Создать» / «Сохранить».

| Поле | Обязательное | Ограничения и пояснения |
|---|---|---|
| «Проект» | нет | Пусто — «Студия — без проекта». Аренду, налоги и подписки студии оставляйте без проекта |
| «Категория» | да | Одна из категорий расходов |
| «Сумма» | да | Число от 0 до 100 000 000 |
| «Валюта» | нет | Код из трёх букв, например `USD`. Пусто — `USD` |
| «Дата» | да | Дата расхода |
| «Контрагент» | нет | «Кому заплатили», до 200 символов |
| «Способ оплаты» | нет | «Перечисление», «Наличные», «Карта», «Другое» или «Не указан» |
| «В т.ч. НДС» | нет | Часть суммы, а не надбавка к ней. Пусто — без НДС. Не может быть больше суммы |
| «Номер документа» | нет | Чек, акт, счёт-фактура; до 80 символов |
| «Ссылка на скан» | нет | Только ссылка, начинающаяся с `http://` или `https://` |
| «Описание» | нет | До 500 символов |

После сохранения панель закрывается, таблица и итоги обновляются.

::tip
Зарплата не попадает в расходы автоматически. Чтобы она учитывалась в [обзоре финансов](/business/finance), внесите её расходом категории «Штат».
::
