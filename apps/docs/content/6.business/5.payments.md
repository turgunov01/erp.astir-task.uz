«Платежи» — деньги от клиентов: и уже полученные, и ожидаемые. Платёж принадлежит [клиенту](/business/clients) и может закрывать выставленный ему [счёт](/business/invoices). Оплаченные платежи — это «Поступления» в [обзоре финансов](/business/finance).

Где в меню: **«Финансы» → «Платежи»**, адрес `/finance/payments`.

![Список платежей](/screenshots/payments.png)

## Доступ

| Что можно | Право | По умолчанию есть у |
|---|---|---|
| Открыть страницу, фильтровать, выгружать CSV | `finance:view` | Владелец, Администратор, Финансы |
| Добавлять, редактировать и удалять платежи | `finance:manage` | Владелец, Администратор, Финансы |

Права ролей студия может менять в настройках (кроме Владельца) — см. [Роли и права](/start/roles). Без права `finance:manage` кнопки «Новый платёж» нет, а в меню строки написано «Недостаточно прав».

## Шапка страницы

- Заголовок «Платежи», под ним — число платежей и период, например «8 платежей · всё время».
- Справа — :icon{name="i-lucide-download"} **«CSV»** и **«Новый платёж»**.

## Период и фильтры

Выбор периода — «Всё время» / «Месяц» / «Квартал» / «Год» / «Период» со стрелками :icon{name="i-lucide-chevron-left"} :icon{name="i-lucide-chevron-right"}. По умолчанию — «Всё время».

::note
Оплаченный платёж относится к дню оплаты, ожидаемый — к своему сроку.
::

| Фильтр | Варианты |
|---|---|
| Клиент | «Все клиенты» или клиент |
| Проект | «Все проекты», «Без проекта» или проект |
| Статус | «Любой статус» или один из статусов (см. ниже) |
| Способ оплаты | «Любой способ», «Перечисление», «Наличные», «Карта», «Другое» |
| Валюта | «Все валюты», `USD`, `UZS`, `EUR`, `RUB` и другие из итогов |
| «Только просроченные» | Галочка: неоплаченные и неотменённые платежи с истёкшим сроком или со статусом «Просрочен» |

Кнопка **«Сбросить»** появляется, когда выбран хотя бы один фильтр.

Поиск — «№ операции, клиент, счёт»: ищет по номеру транзакции, примечанию, имени клиента и номеру счёта.

## Таблица платежей

По 20 записей на странице.

| Колонка | Что показывает |
|---|---|
| «Оплата / срок» | Для оплаченного — дата оплаты и под ней «срок …». Для неоплаченного — срок; если он прошёл, дата красная и подписано «просрочен» |
| «Клиент» | Клиент платежа |
| «Проект» | Проект (ссылка на карточку) или «—» |
| «Счёт» | Номер счёта, который закрывает платёж, или «—» |
| «Способ и № операции» | Способ оплаты и под ним номер транзакции |
| «Сумма» | Сумма, под ней — «комиссия …» (если больше нуля) и примечание |
| «Статус» | Цветной значок статуса |
| (последняя) | :icon{name="i-lucide-ellipsis"} — меню действий |

### Статусы платежа

| Значок | Цвет | Что означает |
|---|---|---|
| «Ожидает оплаты» | жёлтый | Деньги ожидаются (значение по умолчанию) |
| «Оплачен частично» | фиолетовый | Пришла часть суммы |
| «Оплачен» | зелёный | Деньги получены |
| «Просрочен» | красный | Срок прошёл, денег нет |
| «Отменён» | серый | Платёж не состоится |

### Итоги

Под таблицей — итоги по каждой валюте для всех записей под фильтром: «Итого USD · N зап.», «Получено», «Ожидается» и «Комиссии» (если не нулевые).

## Кнопки и действия

| Кнопка / иконка | Что делает | Право |
|---|---|---|
| :icon{name="i-lucide-download"} «CSV» | Скачивает платежи под текущими фильтрами в CSV (не более 5000 строк) | `finance:view` |
| :icon{name="i-lucide-plus"} «Новый платёж» | Открывает форму «Новый платёж» | `finance:manage` |
| «Сбросить» | Сбрасывает фильтры | `finance:view` |
| :icon{name="i-lucide-ellipsis"} | Меню действий со строкой | `finance:view` |
| :icon{name="i-lucide-pencil"} «Редактировать» | Открывает форму «Редактирование платежа» | `finance:manage` |
| :icon{name="i-lucide-trash-2"} «Удалить» | Спрашивает подтверждение и удаляет платёж | `finance:manage` |

::warning
Удаление платежа необратимо: платёж исчезнет из списков и перестанет засчитываться в оплату счёта. Архива у платежей нет.
::

## Форма платежа

Боковая панель «Новый платёж» / «Редактирование платежа», кнопки «Отмена» и «Создать» / «Сохранить».

| Поле | Обязательное | Ограничения и пояснения |
|---|---|---|
| «Клиент» | да | Клиент, от которого платёж |
| «Проект» | нет | Пусто — «Без проекта» |
| «Счёт» | нет | Пусто — «Без счёта». Если платёж закроет счёт целиком, система предложит отметить счёт оплаченным |
| «Сумма» | да | Число от 0 до 100 000 000 |
| «Валюта» | нет | Код из трёх букв. Пусто — `USD` |
| «Статус» | нет | Пусто при создании — «Ожидает оплаты» |
| «Способ» | нет | «Перечисление», «Наличные», «Карта», «Другое» или «Не указан» |
| «Срок» | нет | Когда ожидается оплата |
| «Дата оплаты» | нет | Когда деньги пришли |
| «Номер транзакции» | нет | Платёжное поручение, ID операции; до 120 символов. По нему платёж находится в банковской выписке |
| «Комиссия банка» | нет | Не может быть больше суммы платежа. Пусто — без комиссии |
| «Примечание» | нет | До 1000 символов |

### Окно «Счёт покрыт»

Если сохранённый платёж имеет статус «Оплачен», привязан к счёту, и вместе с другими оплаченными платежами покрывает всю сумму счёта, появляется окно «Счёт покрыт»: «Счёт … на … полностью покрыт платежами. Отметить его оплаченным?»

- **«Отметить оплаченным»** — счёт получает статус «Оплачен».
- **«Оставить как есть»** — статус счёта не меняется.

::note
Статус счёта меняется только этим подтверждением — сам платёж его не трогает. Частичный платёж счёт не закрывает.
::
