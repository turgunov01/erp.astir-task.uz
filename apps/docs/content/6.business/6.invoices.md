«Счета» — счета, выставленные [клиентам](/business/clients). Счёт закрывается [платежами](/business/payments) по нему: страница сама считает, сколько по каждому счёту оплачено и сколько осталось.

Где в меню: **«Финансы» → «Счета»**, адрес `/finance/invoices`.

![Список счетов](/screenshots/invoices.png)

## Доступ

| Что можно | Право | По умолчанию есть у |
|---|---|---|
| Открыть страницу, фильтровать, выгружать CSV | `finance:view` | Владелец, Администратор, Финансы |
| Выставлять, редактировать и удалять счета | `finance:manage` | Владелец, Администратор, Финансы |

Права ролей студия может менять в настройках (кроме Владельца) — см. [Роли и права](/start/roles). Без права `finance:manage` кнопки «Новый счёт» нет, а в меню строки написано «Недостаточно прав».

## Шапка страницы

- Заголовок «Счета», под ним — число счетов и период с пометкой «по дате выставления», например «5 счетов · всё время, по дате выставления».
- Справа — :icon{name="i-lucide-download"} **«CSV»** и **«Новый счёт»**.

## Период и фильтры

Выбор периода — «Всё время» / «Месяц» / «Квартал» / «Год» / «Период» со стрелками :icon{name="i-lucide-chevron-left"} :icon{name="i-lucide-chevron-right"}. По умолчанию — «Всё время». Счёт попадает в период по дате выставления.

| Фильтр | Варианты |
|---|---|
| Клиент | «Все клиенты» или клиент |
| Проект | «Все проекты», «Без проекта» или проект |
| Статус | «Любой статус» или один из статусов (см. ниже) |
| Валюта | «Все валюты», `USD`, `UZS`, `EUR`, `RUB` и другие из итогов |
| «Только просроченные» | Галочка: счета, которые не оплачены и не отменены, а срок оплаты прошёл или статус — «Просрочен» |

Кнопка **«Сбросить»** появляется, когда выбран хотя бы один фильтр.

Поиск — «Номер, клиент, назначение»: ищет по номеру, назначению и имени клиента.

## Таблица счетов

По 20 записей на странице.

| Колонка | Что показывает |
|---|---|
| «Счёт» | Номер, под ним «от …» (дата выставления) и назначение |
| «Клиент» | Клиент и под ним проект (ссылка на карточку) |
| «Оплатить до» | Срок оплаты. У просроченного счёта дата красная, ниже — «просрочен на N дн.» или «просрочен» |
| «Сумма» | Сумма счёта, под ней — «НДС …», если указан |
| «Оплачено» | Сумма оплаченных платежей по счёту, под ней — процент покрытия и число платежей |
| «Остаток» | Сколько осталось получить. У оплаченного или отменённого счёта — «—»; у просроченного остаток красный |
| «Статус» | Цветной значок статуса |
| (последняя) | :icon{name="i-lucide-ellipsis"} — меню действий |

::note
В «Оплачено» учитываются только платежи со статусом «Оплачен».
::

### Статусы счёта

| Значок | Цвет | Что означает |
|---|---|---|
| «Ожидает оплаты» | жёлтый | Счёт выставлен, деньги ждут (значение по умолчанию) |
| «Оплачен частично» | фиолетовый | Получена часть суммы |
| «Оплачен» | зелёный | Счёт закрыт |
| «Просрочен» | красный | Срок прошёл, счёт не оплачен |
| «Отменён» | серый | Счёт аннулирован |

Счёт считается просроченным и по сроку: у неоплаченного счёта с прошедшей датой «Оплатить до» дата становится красной, а сам счёт попадает в фильтр «Только просроченные» и в «Просрочено» в итогах, даже если статус вручную не меняли. Значок статуса при этом остаётся прежним.

### Итоги

Под таблицей — итоги по каждой валюте для всех записей под фильтром: «Итого USD · N зап.», «Выставлено», «Оплачено», «Осталось получить» и «Просрочено» (если не нулевое).

## Кнопки и действия

| Кнопка / иконка | Что делает | Право |
|---|---|---|
| :icon{name="i-lucide-download"} «CSV» | Скачивает счета под текущими фильтрами в CSV (не более 5000 строк) | `finance:view` |
| :icon{name="i-lucide-plus"} «Новый счёт» | Открывает форму «Новый счёт» | `finance:manage` |
| «Сбросить» | Сбрасывает фильтры | `finance:view` |
| :icon{name="i-lucide-ellipsis"} | Меню действий со строкой | `finance:view` |
| :icon{name="i-lucide-pencil"} «Редактировать» | Открывает форму «Редактирование счёта» | `finance:manage` |
| :icon{name="i-lucide-trash-2"} «Удалить» | Спрашивает подтверждение и удаляет счёт | `finance:manage` |

::warning
Удаление счёта необратимо: счёт исчезнет из списков. Платежи по нему останутся, но потеряют привязку. Архива у счетов нет.
::

## Форма счёта

Боковая панель «Новый счёт» / «Редактирование счёта», кнопки «Отмена» и «Создать» / «Сохранить».

| Поле | Обязательное | Ограничения и пояснения |
|---|---|---|
| «Номер» | нет | До 40 символов. Пусто — присвоится следующий номер вида `INV-0001`. Номер уникален и уходит клиенту, поэтому менять его стоит осознанно |
| «Клиент» | да | Кому выставлен счёт |
| «Проект» | нет | Пусто — «Без проекта» |
| «Сумма» | да | Число от 0 до 100 000 000 |
| «Валюта» | нет | Код из трёх букв. Пусто — `USD` |
| «Статус» | нет | Пусто при создании — «Ожидает оплаты» |
| «Выставлен» | нет | Дата выставления. Пусто — сегодня |
| «Оплатить до» | нет | Срок оплаты |
| «В т.ч. НДС» | нет | Часть суммы счёта. Пусто — без НДС. Не может быть больше суммы |
| «Назначение» | нет | За что выставлен счёт; до 1000 символов |

::tip
Отмечать счёт оплаченным вручную не обязательно: когда сохранённый на странице [Платежи](/business/payments) платёж полностью покроет счёт, система сама предложит это сделать.
::
