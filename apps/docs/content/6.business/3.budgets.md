«Бюджеты» — план проекта рядом с фактом. В бюджете задаются только плановая выручка и плановая себестоимость. Факт не вводится вручную: это расходы проекта плюс оплаченные по ставке часы из табеля, в валюте бюджета. Сводка по всем проектам — в [обзоре финансов](/business/finance).

Где в меню: **«Финансы» → «Бюджеты»**, адрес `/finance/budgets`.

![Бюджеты проектов](/screenshots/budgets.png)

## Доступ

| Что можно | Право | По умолчанию есть у |
|---|---|---|
| Открыть страницу, видеть бюджеты и разбивку по категориям | `budget:view` | Владелец, Администратор, Продюсер, Финансы |
| Создавать, редактировать и удалять бюджеты, задавать план по категориям | `finance:manage` | Владелец, Администратор, Финансы |

Права ролей студия может менять в настройках (кроме Владельца) — см. [Роли и права](/start/roles).

Без права `finance:manage` кнопки «Новый бюджет» нет, в меню строки написано «Недостаточно прав», а окно «Бюджет по категориям» открывается только для просмотра.

## Шапка страницы

Над заголовком — подпись «Финансы», заголовок — «Бюджеты». Под ним — пояснение со ссылкой «обзоре финансов» и справа кнопка **«Новый бюджет»**.

## Таблица бюджетов

Над таблицей — поиск «Проект или клиент»: ищет по коду и названию проекта и имени клиента. Все бюджеты загружаются сразу (у проекта бывает только один бюджет), поэтому постраничного разбиения нет.

| Колонка | Что показывает |
|---|---|
| «Проект» | Название проекта (ссылка на карточку проекта), под ним — значок статуса проекта и имя клиента |
| «План: выручка / затраты» | Плановая выручка, под ней — «затраты …» (плановая себестоимость) |
| «Факт расходов» | Расходы проекта + стоимость часов по ставке сотрудников. Ниже — полоска освоения и подпись «освоено N%» (или «нет плана затрат») и «труд …» — стоимость часов. Если есть расходы или платежи в другой валюте — «+ суммы в …» |
| «Поступило» | Сумма оплаченных платежей по проекту, под ней — «выставлено …» (сумма счетов, кроме отменённых) |
| «Маржа план / факт» | Плановая маржа в процентах: (выручка − затраты) ÷ выручка. Под ней — «факт …»: поступило − факт расходов (зелёная или красная). Ниже — кнопка «По категориям» |
| (последняя) | Кнопка :icon{name="i-lucide-ellipsis"} — меню действий |

В факт идут только деньги в валюте бюджета; суммы в других валютах не пересчитываются, а только перечисляются.

### Цвет полоски освоения

| Цвет | Что означает |
|---|---|
| зелёный | Израсходовано меньше 85% плановой себестоимости |
| жёлтый | От 85% до 100% |
| красный | Больше 100% — себестоимость превышена (сумма факта тоже становится красной) |
| серый | Плановая себестоимость не задана |

## Кнопки и действия

| Кнопка / иконка | Что делает | Право |
|---|---|---|
| :icon{name="i-lucide-plus"} «Новый бюджет» | Открывает форму «Бюджет проекта» | `finance:manage` |
| :icon{name="i-lucide-list-tree"} «По категориям» | Открывает окно «Бюджет по категориям». В скобках — число категорий с планом | `budget:view` |
| :icon{name="i-lucide-ellipsis"} | Меню действий со строкой | `budget:view` |
| :icon{name="i-lucide-pencil"} «Редактировать» | Открывает форму «Редактирование бюджета» | `finance:manage` |
| :icon{name="i-lucide-trash-2"} «Удалить» | Спрашивает подтверждение и удаляет бюджет | `finance:manage` |

::warning
Удаление бюджета необратимо: плановые цифры и разбивка по категориям исчезнут, и проект будет считаться по бюджету из его карточки.
::

## Форма бюджета

Боковая панель «Бюджет проекта» (при редактировании — «Редактирование бюджета»), кнопки «Отмена» и «Создать» / «Сохранить».

| Поле | Обязательное | Ограничения и пояснения |
|---|---|---|
| «Проект» | да | Выбирается только при создании. У проекта один бюджет: сохранение поверх существующего обновит его |
| «Плановая выручка» | да | Число от 0 до 100 000 000 |
| «Плановая себестоимость» | да | Число от 0 до 100 000 000 |
| «Валюта» | нет | Код из трёх букв, например `USD`. Пусто — `USD` |

Фактическую себестоимость в форму не вводят — она считается сама.

## Окно «Бюджет по категориям»

Показывает, сколько запланировано и сколько потрачено по каждой категории расходов («Штат», «Подряд», «Рендер», «Софт», «Железо», «Звук», «Продакшн», «Аренда и офис», «Налоги и сборы», «Маркетинг», «Прочее»).

- Колонки: «Категория», «План», «Факт». Под фактом — процент от плана; если план не задан, а расходы есть — «без плана».
- Строка «Итого» — суммы по всем категориям.
- Если сумма плана по категориям не совпадает с плановой себестоимостью бюджета, появляется предупреждение «Сумма по категориям … не совпадает с плановой себестоимостью бюджета …».
- Если у проекта есть расходы в другой валюте — «Есть расходы в … — в факт бюджета в … они не входят.»

::note
Факт по категориям — это расходы проекта в этой категории. Труд по таймшитам в разбивку не входит.
::

С правом `finance:manage` в колонке «План» — поля ввода для каждой категории и кнопки «Отмена» и **«Сохранить план»**. Категории с пустым или нулевым планом не сохраняются. Без права окно только показывает категории, где есть план или факт. Закрыть окно — кнопка :icon{name="i-lucide-x"} или клавиша :kbd{value="Esc"}.
