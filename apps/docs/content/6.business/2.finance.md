«Финансовый обзор» — стартовая страница финансов. Это кассовый взгляд на период: поступления — оплаченные платежи, расходы — внесённые расходы. Дебиторка и просрочка считаются на сегодня, независимо от выбранного периода. Суммы в разных валютах никогда не складываются: на каждую валюту — своя строка показателей.

Где в меню: **«Финансы» → «Обзор»**, адрес `/finance`.

![Финансовый обзор](/screenshots/finance.png)

## Доступ

| Что можно | Право | По умолчанию есть у |
|---|---|---|
| Открыть страницу | `finance:view` | Владелец, Администратор, Финансы |
| Видеть зарплатные цифры (показатель «Зарплата к выплате» и блок «Зарплата за …») | `payroll:view` | Владелец, Администратор, Финансы |

Права ролей студия может менять в настройках (кроме Владельца) — см. [Роли и права](/start/roles).

Без права `payroll:view` в показателе «Зарплата к выплате» написано «нет доступа к зарплатам», а блок зарплаты внизу страницы не показывается. Ссылки на соседние разделы (см. ниже) показываются только те, на которые у пользователя есть право.

Страница только показывает данные — ничего изменить на ней нельзя.

## Шапка и выбор периода

Под заголовком «Финансовый обзор» — выбор периода. По умолчанию открывается текущий месяц.

| Элемент | Что делает |
|---|---|
| «Месяц» / «Квартал» / «Год» / «Период» | Масштаб периода. При смене масштаба сохраняется год (или квартал), который был на экране |
| :icon{name="i-lucide-chevron-left"} / :icon{name="i-lucide-chevron-right"} | Предыдущий / следующий месяц, квартал или год. Между стрелками — название текущего периода |
| Поля «с» и «по» | Появляются при выборе «Период»: начальная и конечная дата произвольного диапазона |
| Кнопки валют (например, `USD`, `UZS`) | Появляются, только если за период есть деньги в нескольких валютах. Выбирают валюту графиков «Движение денег по месяцам» и «Расходы по категориям» |

Выбранный период и валюта сохраняются в адресе страницы, поэтому ссылкой можно поделиться.

Если за период нет ни платежей, ни расходов, ни открытых счетов, страница пишет «За … нет ни платежей, ни расходов, ни открытых счетов.»

## Показатели по валюте

Для каждой валюты — полоса из шести карточек:

| Карточка | Что показывает |
|---|---|
| «Поступления · USD» | Сумма оплаченных платежей за период. Под ней — «выставлено …» (сумма счетов) и, если есть, «комиссии …» |
| «Расходы» | Сумма расходов за период. Ссылка «все расходы →» открывает [Расходы](/business/expenses) с тем же периодом и валютой |
| «Прибыль» | Поступления − комиссии − расходы. Отрицательная прибыль — красная |
| «Дебиторка» | Неоплаченный остаток счетов на сегодня |
| «Просрочено» | Сумма просроченных счетов на сегодня (красная, если больше нуля). Ссылка с числом счетов открывает [Счета](/business/invoices) с фильтром «Только просроченные» |
| «Зарплата к выплате» | Итог «К выплате» из расчёта зарплаты за месяц (подпись «за …»). Без права `payroll:view` — «нет доступа к зарплатам» |

## Ссылки на разделы

Под показателями — ряд кнопок-ссылок: «Бюджеты», «Расходы», «Платежи», «Счета», «Зарплата: авансы, штрафы, премии» и «Финансовый отчёт». Каждая показывается, только если у пользователя есть право на соответствующую страницу.

## Движение денег по месяцам

Столбчатый график за выбранный период в выбранной валюте: зелёные столбцы — «Поступления», красные — «Расходы». Под каждой парой столбцов — итог месяца. Если навести на столбец, появится подсказка с суммой.

## Расходы по категориям

Расходы периода в выбранной валюте, разложенные по категориям («Штат», «Подряд», «Рендер», «Софт» и т. д.), с суммой и долей в процентах. В подзаголовке — общая сумма. Щелчок по категории открывает [Расходы](/business/expenses), отфильтрованные по этой категории, периоду и валюте.

## Прибыльность проектов

Таблица по всем проектам, кроме отменённых и архивных, у которых есть бюджет или движение денег. Цифры накопительные — по последний день выбранного периода. Худшая маржа — сверху.

| Колонка | Что показывает |
|---|---|
| «Проект» | Название проекта |
| «Бюджет» | Плановая выручка, под ней — «затраты …» (плановая себестоимость). Если бюджета нет — «нет бюджета» |
| «Факт расходов» | Расходы проекта + оплаченные по ставке часы; под суммой — «расходы … · труд …» |
| «Поступления» | Оплаченные платежи по проекту; под ними — «выставлено …» |
| «Маржа» | Поступления − факт расходов и процент от поступлений. Если денег ещё не поступало — «оплат не было» |
| «Освоение бюджета» | Какая доля плановой себестоимости уже израсходована («… плана затрат»). Без плановой себестоимости — «нет плана затрат» |

Если у проекта есть суммы в другой валюте, под строкой написано «+ суммы в … не учтены».

## Просроченные счета и ближайшие оплаты

Два списка рядом:

- **«Просроченные счета»** — до 8 неоплаченных счетов с истёкшим сроком или отмеченных просроченными. В строке — номер, клиент, срок, сколько дней просрочки (или «отмечен просроченным»), остаток к оплате и «из …» — полная сумма. Ссылка «все →» открывает [Счета](/business/invoices) с фильтром «Только просроченные».
- **«К оплате в ближайшие 14 дней»** — до 8 открытых счетов, срок оплаты которых наступает в ближайшие 14 дней, с отметкой «сегодня» или «через N дн.». Если счетов больше, чем показано, — «Показаны … из …».

Щелчок по счёту открывает список счетов с поиском по его номеру.

## Зарплата за месяц

Блок «Зарплата за …» виден только с правом `payroll:view`. Месяц — последний месяц выбранного периода (но не будущий). Учтены утверждённые и выплаченные записи.

::note
Зарплата не входит в расходы на этой странице, пока её не внесли расходом категории «Штат».
::

Таблица по валютам: «Валюта», «Оклады», «Премии», «Авансы», «Штрафы» (вместе со штрафами за опоздания, под суммой — «опозданий N · M мин»), «Удержания», «К выплате». Если в месяце есть неутверждённые записи, под валютой написано «не учтено: N черновиков».

Если выбран период длиннее месяца, внизу блока — строка «За весь период: …» с суммами утверждённых записей каждого вида («Авансы», «Премии», «Штрафы» и т. д.) и их количеством.

Кнопка **«Открыть расчёт»** :icon{name="i-lucide-arrow-right"} открывает страницу [Зарплата](/business/payroll) на этом месяце.
