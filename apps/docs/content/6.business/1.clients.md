Раздел «Клиенты» — список заказчиков студии. Клиент — владелец проектов и получатель поставки; к нему привязываются проекты, [счета](/business/invoices) и [платежи](/business/payments).

Где в меню: пункт **«Клиенты»** в боковом меню, адрес `/clients`.

![Список клиентов](/screenshots/clients.png)

## Доступ

| Что можно | Право | По умолчанию есть у |
|---|---|---|
| Открыть раздел и видеть список | `client:view` | Владелец, Администратор, Продюсер, Менеджер проекта, Финансы |
| Создавать, редактировать, архивировать и удалять клиентов | `client:manage` | Владелец, Администратор |

Права ролей студия может менять в настройках (кроме Владельца) — подробнее в разделе [Роли и права](/start/roles).

Без права `client:manage` кнопка «Новый клиент» не показывается, а в меню строки вместо действий написано «Недостаточно прав».

## Шапка страницы

- Над заголовком — подпись «Коммерция», заголовок — «Клиенты».
- Под заголовком — число клиентов в текущем наборе, например «3 клиента».
- Справа — переключатель **«Активные» / «Архив»** и кнопка **«Новый клиент»**.

Переключатель выбирает, что показывает таблица: рабочий список или архив. При переключении таблица возвращается на первую страницу.

## Таблица клиентов

Над таблицей — строка поиска «Поиск по имени, компании, почте...». Поиск идёт по имени клиента, названию компании и почте без учёта регистра. Таблица показывает по 20 клиентов на странице.

| Колонка | Что показывает |
|---|---|
| «Клиент» | Имя клиента, под ним серым — название компании (если указано) |
| «Почта» | Адрес почты; щелчок открывает почтовую программу. Если почты нет — «—» |
| «Страна» | Страна клиента |
| «Проекты» | Сколько проектов привязано к клиенту |
| «Статус» | Цветной значок статуса (см. ниже) |
| (последняя) | Кнопка :icon{name="i-lucide-ellipsis"} — меню действий со строкой |

Если клиентов ещё нет, таблица показывает «Пока нет клиентов».

### Статусы клиента

| Значок | Цвет | Что означает |
|---|---|---|
| «Активен» | зелёный | С клиентом идёт работа (значение по умолчанию для нового клиента) |
| «Неактивен» | серый | Клиент сохранён, но сейчас работы с ним нет |
| «В архиве» | серый | Клиент удалён из рабочего списка (этот статус ставится при удалении) |

## Кнопки и действия

| Кнопка / иконка | Что делает | Право |
|---|---|---|
| «Активные» / «Архив» | Переключает таблицу между рабочим списком и архивом | `client:view` |
| :icon{name="i-lucide-plus"} «Новый клиент» | Открывает форму создания клиента | `client:manage` |
| :icon{name="i-lucide-ellipsis"} | Открывает меню действий со строкой | `client:view` |
| :icon{name="i-lucide-pencil"} «Редактировать» | Открывает форму редактирования клиента (только в рабочем списке) | `client:manage` |
| :icon{name="i-lucide-archive"} «Архивировать» | Убирает клиента в архив; вернуть можно из вида «Архив» | `client:manage` |
| :icon{name="i-lucide-archive-restore"} «Вернуть из архива» | Возвращает клиента в рабочий список (только в виде «Архив») | `client:manage` |
| :icon{name="i-lucide-trash-2"} «Удалить» | Спрашивает подтверждение и удаляет клиента из списков | `client:manage` |

### Архивирование и удаление

- **Архивирование** обратимо: клиент пропадает из вида «Активные» и появляется в виде «Архив», откуда его возвращают действием «Вернуть из архива».
- **Удаление** открывает окно «Удаление» с вопросом «Удалить клиента «…»?» и кнопкой «Удалить». После подтверждения клиент исчезает из списков, а его статус становится «В архиве».

::warning
Вернуть удалённого клиента через интерфейс нельзя. Для обратимого скрытия используйте «Архивировать».
::

::note
Клиента с активными проектами удалить нельзя: система ответит «У клиента есть активные проекты: N. Сначала завершите или переназначьте их.» Активными считаются все проекты клиента, кроме завершённых, отменённых и архивных.
::

## Форма клиента

Форма открывается боковой панелью справа: «Новый клиент» при создании и «Редактирование клиента» при изменении. Внизу — кнопки «Отмена» и «Создать» (при редактировании — «Сохранить»).

| Поле | Обязательное | Ограничения и пояснения |
|---|---|---|
| «Имя» | да | От 2 до 160 символов. Подсказка в поле — «Как обращаться» |
| «Компания» | нет | До 160 символов |
| «Почта» | нет | Должна быть корректным адресом почты |
| «Телефон» | нет | До 40 символов |
| «Страна» | нет | До 80 символов |
| «Статус» | нет | «Активен», «Неактивен» или «В архиве». Пусто при создании — «Активен» |
| «Заметки» | нет | До 4000 символов |
| «Файлы» | нет | Фото, видео, аудио или документ; кнопка «Выбрать фото, видео, аудио или документ (до 1 ГБ)». Файлы загружаются сразу после сохранения |

После сохранения панель закрывается, а таблица обновляется.
