Раздел «Правки» — список доработок по версиям и шотам. Правка появляется автоматически, когда на [согласовании](/production/reviews) версию возвращают кнопкой «На доработку», или её заводят вручную. Каждая правка имеет номер раунда: первый возврат — раунд 1, следующий по той же версии — раунд 2 и так далее.

Где в меню: **«Производство» → «Правки»**, адрес `/revisions`.

![Правки](/screenshots/revisions.png)

## Доступ

| Что можно | Право | По умолчанию есть у |
|---|---|---|
| Открыть раздел и видеть правки | `revision:view` | Владелец, Администратор, Продюсер, Менеджер проекта, Арт-директор, Художник, Клиент |
| Менять статус правки в таблице и редактировать правку | `task:update` | Владелец, Администратор, Продюсер, Менеджер проекта, Художник |
| Создавать, архивировать и удалять правки | `revision:manage` | Владелец, Администратор, Продюсер, Менеджер проекта, Арт-директор |

Права ролей студия может менять в настройках (кроме Владельца) — подробнее в разделе [Роли и права](/start/roles).

Без права `task:update` в колонке «Статус» вместо выпадающего списка показывается значок. Без права `revision:manage` кнопки «Новая правка» нет, а в меню строки написано «Недостаточно прав».

::note
Сохранение формы редактирования правки сервер принимает только при праве `task:update`. Поэтому Арт-директор по умолчанию может создавать, архивировать и удалять правки, но не может их редактировать.
::

## Шапка страницы

- Над заголовком — подпись «Производство», заголовок — «Правки».
- Под заголовком — сводка «N открыто · N в работе · N завершено».

## Выборки

Ряд кнопок под шапкой; рядом с каждой — число правок в этом статусе. Выбранная выборка запоминается в адресе (`?view=…`).

| Выборка | Что показывает |
|---|---|
| «Открытые» | Статус «Открыта» (выбрана по умолчанию) |
| «В работе» | Статус «В работе» |
| «На проверке» | Статус «На проверке» |
| «Завершённые» | Статус «Завершена» |
| «Все» | Все правки, включая отменённые |

Справа над таблицей — переключатель **«Активные» / «Архив»** и кнопка **«Новая правка»**.

## Таблица

В строке поиска написано «Поиск недоступен в этом разделе» — набор сужается выборками и фильтром **«Все проекты»**. Таблица показывает по 25 правок на странице.

| Колонка | Что показывает |
|---|---|
| «Правка» | Название правки. Под ним — код шота (ссылка на шот), название задачи (щелчок открывает панель задачи) и «от <имя>» — кто запросил правку |
| «Раунд» | Номер раунда |
| «Проект» | Ссылка на карточку проекта |
| «Исполнитель» | Кто исправляет, или «не назначен» |
| «Срок» | Срок правки; просроченный срок — красный |
| «Статус» | Выпадающий список статусов (при праве `task:update`) или значок |
| (последняя) | Кнопка :icon{name="i-lucide-ellipsis"} — меню действий |

Правка считается просроченной, если срок прошёл, а статус не «Завершена» и не «Отменена».

Выбор нового статуса в колонке «Статус» сохраняется сразу; сводка и счётчики выборок обновляются. Если сохранить не удалось, над таблицей появляется «Не удалось обновить правку».

Если правок нет — «Правок нет».

## Панель правки

Щелчок по строке открывает панель с подзаголовком «Правка · раунд N».

Вверху — значок статуса, приоритет и, если срок прошёл, красная метка «Просрочена». Ниже — «Описание» (текст правки; для правки из согласования — комментарий проверяющего) и сведения:

| Поле | Что показывает |
|---|---|
| «Статус» | Текущий статус |
| «Раунд» | Номер раунда |
| «Проект» | Код и название проекта — ссылка |
| «Шот» | Ссылка на шот |
| «Задача» | Задача — щелчок открывает её панель |
| «Версия» | Версия, по которой сделана правка |
| «Автор» | Кто запросил правку |
| «Исполнитель» | Кто исправляет |
| «Срок» | Срок; просроченный — красный |
| «Создана», «Обновлена», «Завершена» | Дата и время событий |

## Создание и редактирование

Кнопка **«Новая правка»** открывает форму «Новая правка», пункт «Редактировать» в меню строки — «Редактирование правки».

| Поле | Обязательное | Что вводить |
|---|---|---|
| «Проект» | да | Только при создании |
| «Правка» | да | Название, от 2 до 200 символов |
| «Шот» | нет | Шот, к которому относится правка |
| «Задача» | нет | Связанная задача |
| «Исполнитель» | нет | Кто будет исправлять |
| «Приоритет» | нет | «Низкий», «Обычный», «Высокий», «Срочный»; по умолчанию «Обычный» |
| «Статус» | нет | Только при редактировании |
| «Срок» | нет | Дата |
| «Описание» | нет | До 4000 символов |
| «Файлы» | нет | Фото, видео, аудио или документ — загрузятся сразу после сохранения |

Новая правка создаётся в статусе «Открыта». Номер раунда проставляется автоматически: следующий после последней правки той же версии, а для правки без версии — того же шота. Назначенный исполнитель получает уведомление.

При смене исполнителя новый исполнитель тоже получает уведомление. При переводе в «Завершена» запоминается дата завершения; при возврате в другой статус она сбрасывается.

## Статусы правки

| Значок | Цвет | Что означает |
|---|---|---|
| «Открыта» | серый | Правка заведена, работа не начата |
| «В работе» | серый | Исполнитель исправляет |
| «На проверке» | серый | Исправление готово и ждёт проверки |
| «Завершена» | зелёный | Правка закрыта (в значке может отображаться как «Завершён») |
| «Отменена» | красный | Правка больше не нужна (в значке может отображаться как «Отменён») |

## Кнопки и действия

| Кнопка / иконка | Что делает | Право |
|---|---|---|
| Выборки «Открытые» … «Все» | Меняют набор правок | `revision:view` |
| «Все проекты» | Показывает правки одного проекта | `revision:view` |
| «Активные» / «Архив» | Переключает таблицу между рабочим списком и архивом | `revision:view` |
| :icon{name="i-lucide-plus"} «Новая правка» | Открывает форму создания | `revision:manage` |
| Выпадающий список в колонке «Статус» | Сразу меняет статус правки | `task:update` |
| :icon{name="i-lucide-ellipsis"} → :icon{name="i-lucide-pencil"} «Редактировать» | Открывает форму редактирования | `revision:manage` (сохранение — `task:update`) |
| :icon{name="i-lucide-ellipsis"} → :icon{name="i-lucide-archive"} «Архивировать» | Сразу переносит правку в архив | `revision:manage` |
| :icon{name="i-lucide-ellipsis"} → :icon{name="i-lucide-archive-restore"} «Вернуть из архива» | Возвращает правку из архива | `revision:manage` |
| :icon{name="i-lucide-ellipsis"} → :icon{name="i-lucide-trash-2"} «Удалить» | После подтверждения удаляет правку | `revision:manage` |

::warning
Удалённую правку вернуть через интерфейс нельзя. Чтобы убрать правку из рабочего списка обратимо, используйте архив.
::
