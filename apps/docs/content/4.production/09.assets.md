Раздел «Библиотека ассетов» — каталог производственных ассетов: персонажей, окружений, пропсов, моделей, ригов, текстур и прочего. Ассет может принадлежать проекту или быть общим для всей студии. У каждого ассета видны владелец, статус и история версий.

Где в меню: **«Производство» → «Библиотека ассетов»**, адрес `/assets`.

![Библиотека ассетов](/screenshots/assets.png)

## Доступ

| Что можно | Право | По умолчанию есть у |
|---|---|---|
| Открыть раздел и смотреть ассеты | `asset:view` | Владелец, Администратор, Продюсер, Менеджер проекта, Арт-директор, Художник |
| Создавать, редактировать, архивировать и удалять ассеты | `asset:manage` | Владелец, Администратор, Менеджер проекта, Арт-директор |

Права ролей студия может менять в настройках (кроме Владельца) — подробнее в разделе [Роли и права](/start/roles).

Без права `asset:manage` кнопки «Новый ассет» нет, а в меню строки написано «Недостаточно прав».

## Шапка страницы

- Над заголовком — подпись «Производство», заголовок — «Библиотека ассетов».
- Под заголовком — число ассетов в текущем наборе, например «12 ассетов».
- Справа над таблицей — переключатель **«Активные» / «Архив»** и кнопка **«Новый ассет»**.

## Поиск и фильтры

- Строка поиска «Поиск по названию...» — ищет по названию ассета без учёта регистра.
- «Все типы» — ассеты одного типа.
- «Все проекты» — ассеты одного проекта.

Таблица показывает по 10 ассетов на странице.

## Таблица

| Колонка | Что показывает |
|---|---|
| «Ассет» | Миниатюра (или иконка :icon{name="i-lucide-box"}, если превью нет) и название |
| «Тип» | Тип ассета (см. ниже) |
| «Проект» | Ссылка на проект или «общий» — ассет не привязан к проекту |
| «Владелец» | Ответственный за ассет или «—» |
| «Версий» | Сколько версий у ассета |
| «Статус» | Значок статуса (см. ниже) |
| (последняя) | Кнопка :icon{name="i-lucide-ellipsis"} — меню действий |

Если ассетов нет — «Библиотека пуста».

### Типы ассетов

«Персонаж», «Окружение», «Пропс», «Модель», «Риг», «Текстура», «Анимация», «Звук», «Референс», «Шаблон», «Прочее».

## Панель ассета

Щелчок по строке открывает панель: заголовок — название ассета, подзаголовок — его тип.

- **Обложка** — если задана ссылка на превью. Щелчок открывает её в полноэкранном просмотре.
- Значок статуса и число версий, например «3 версии».
- «Описание», если оно заполнено.
- Сведения: «Статус», «Проект» (или «общий»), «Владелец», «Создан», «Обновлён».
- **«Версии»** — история версий: миниатюра файла (щелчок открывает просмотр), название версии, номер «vN», дата и время загрузки и значок статуса версии. Если версий нет — «У ассета пока нет версий.»

## Создание и редактирование

Кнопка **«Новый ассет»** открывает форму «Новый ассет», пункт «Редактировать» в меню строки — «Редактирование ассета».

| Поле | Обязательное | Что вводить |
|---|---|---|
| «Название» | да | От 2 до 200 символов |
| «Тип» | да | Один из типов ассета |
| «Проект» | нет | Проект; по умолчанию «Общий» — ассет доступен всей студии |
| «Владелец» | нет | Ответственный сотрудник |
| «Статус» | нет | По умолчанию «Не начато» |
| «Ссылка на превью» | нет | Адрес картинки-обложки, до 500 символов |
| «Описание» | нет | До 4000 символов |
| «Файлы» | нет | Фото, видео, аудио или документ — загрузятся сразу после сохранения |

Кнопка **«Создать»** (при редактировании — «Сохранить») сохраняет ассет, таблица обновляется.

## Статусы ассета

| Значок | Цвет | Что означает |
|---|---|---|
| «Не начато» | серый | Работа над ассетом не начиналась |
| «В работе» | серый | Ассет в работе |
| «На проверке» | серый | Ассет ждёт проверки |
| «На правках» | серый | Ассет дорабатывают |
| «Утверждено» | серый | Ассет принят (в значке может отображаться как «Согласовано») |
| «Завершено» | зелёный | Ассет готов (в значке может отображаться как «Завершён») |
| «Приостановлено» | жёлтый | Работа над ассетом на паузе (в значке может отображаться как «Приостановлен») |

## Кнопки и действия

| Кнопка / иконка | Что делает | Право |
|---|---|---|
| «Активные» / «Архив» | Переключает таблицу между рабочим списком и архивом | `asset:view` |
| :icon{name="i-lucide-plus"} «Новый ассет» | Открывает форму создания ассета | `asset:manage` |
| :icon{name="i-lucide-ellipsis"} → :icon{name="i-lucide-pencil"} «Редактировать» | Открывает форму редактирования | `asset:manage` |
| :icon{name="i-lucide-ellipsis"} → :icon{name="i-lucide-archive"} «Архивировать» | Сразу переносит ассет в архив | `asset:manage` |
| :icon{name="i-lucide-ellipsis"} → :icon{name="i-lucide-archive-restore"} «Вернуть из архива» | Возвращает ассет из архива | `asset:manage` |
| :icon{name="i-lucide-ellipsis"} → :icon{name="i-lucide-trash-2"} «Удалить» | После подтверждения удаляет ассет | `asset:manage` |

::warning
Удалённый ассет вернуть через интерфейс нельзя. Для обратимого скрытия используйте архив.
::
