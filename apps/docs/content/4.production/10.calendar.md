Раздел «Календарь» показывает на одной месячной сетке всё, у чего есть дата: сдачи проектов, вехи проектов и дедлайны задач. Это общий план студии на месяц; для работы только с задачами есть отдельный [календарь задач](/production/tasks) с фильтрами.

Где в меню: пункт **«Календарь»** в боковом меню (сразу после группы «Производство»), адрес `/calendar`.

![Календарь](/screenshots/calendar.png)

## Доступ

| Что можно | Право | По умолчанию есть у |
|---|---|---|
| Открыть раздел | `production:view` | Владелец, Администратор, Продюсер, Менеджер проекта, Арт-директор, Художник |
| Получить данные календаря | `dashboard:view` | Владелец, Администратор, Продюсер, Менеджер проекта, Арт-директор, Художник, Финансы |

Права ролей студия может менять в настройках (кроме Владельца) — подробнее в разделе [Роли и права](/start/roles).

Сдачи проектов и вехи видны всем, кто открыл раздел. Задачи — с учётом права на задачи: при праве `task:view` показываются все задачи студии, без него (по умолчанию у Художника) — только задачи, где исполнитель вы.

::note
Если у роли есть `production:view`, но нет `dashboard:view`, раздел откроется, но календарь покажет «Не удалось загрузить календарь».
::

## Шапка страницы

- Над заголовком — подпись «Планирование», заголовок — «Календарь».
- Под заголовком — сводка за показанный месяц, например «2 сдачи проектов · 3 вехи · 14 задач в этом месяце».
- Справа — переключение месяца:
  - :icon{name="i-lucide-chevron-left"} — предыдущий месяц;
  - название месяца и год;
  - :icon{name="i-lucide-chevron-right"} — следующий месяц;
  - **«Сегодня»** — вернуться к текущему месяцу (кнопка появляется, только когда открыт другой месяц).

## Легенда

Под шапкой — легенда цветов событий:

| Цвет | Событие | Что показывает | Щелчок |
|---|---|---|---|
| красный | «сдача проекта» | Дедлайн проекта в виде «<код проекта> · сдача» | Открывает карточку проекта |
| фиолетовый | «веха» | Название вехи проекта | — |
| синий | «задача» | Название задачи с дедлайном на этот день | Открывает панель задачи |

При наведении на событие всплывает подсказка с названием и проектом.

Выполненное событие зачёркнуто и приглушено: проект в статусе «Завершён», веха с отметкой о выполнении, задача в статусе «Утверждена» или «Завершена».

## Сетка месяца

- Шесть недель, неделя начинается с понедельника; дни соседних месяцев приглушены.
- Сегодняшний день обведён рамкой.
- В ячейке — число месяца и до трёх событий. Если событий больше — строка «ещё N».

::tip
Если в день больше трёх задач, откройте [календарь задач](/production/tasks): там щелчок по дню показывает полный список задач этой даты.
::

Если загрузить данные не удалось, вместо сетки появляется «Не удалось загрузить календарь» и кнопка **«Повторить»**.

## Кнопки и действия

| Кнопка / иконка | Что делает | Право |
|---|---|---|
| :icon{name="i-lucide-chevron-left"} | Показывает предыдущий месяц | `production:view` |
| :icon{name="i-lucide-chevron-right"} | Показывает следующий месяц | `production:view` |
| «Сегодня» | Возвращает к текущему месяцу | `production:view` |
| Событие «сдача» | Открывает карточку проекта | `project:view` |
| Событие «задача» | Открывает панель задачи | `task:view:own` |
| «Повторить» | Повторно загружает календарь после ошибки | `production:view` |
