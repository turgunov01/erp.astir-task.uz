Раздел «Эпизоды» собирает эпизоды всех проектов студии в одну таблицу. Эпизод — верхний уровень производственной структуры: внутри него живут [сцены](/production/scenes), а в сценах — [шоты](/production/shots).

Где в меню: **«Производство» → «Эпизоды»**, адрес `/episodes`.

![Список эпизодов](/screenshots/episodes.png)

## Доступ

| Что можно | Право | По умолчанию есть у |
|---|---|---|
| Открыть раздел и видеть список | `production:view` | Владелец, Администратор, Продюсер, Менеджер проекта, Арт-директор, Художник |
| Создавать, редактировать, архивировать и удалять эпизоды | `production:manage` | Владелец, Администратор, Продюсер, Менеджер проекта |
| Прикреплять файлы в форме эпизода | `document:manage` | Владелец, Администратор, Финансы |

Права ролей студия может менять в настройках (кроме Владельца) — подробнее в разделе [Роли и права](/start/roles).

Без права `production:manage` кнопки «Новый эпизод» нет, а в меню строки вместо действий написано «Недостаточно прав».

## Шапка страницы

- Над заголовком — подпись «Производство», заголовок — «Эпизоды», под ним — число эпизодов в выборке, например «8 эпизодов».
- Справа — переключатель **«Активные» / «Архив»** и кнопка **«Новый эпизод»**.

При переключении между «Активные» и «Архив» таблица возвращается на первую страницу.

## Поиск и фильтры

- Строка поиска «Поиск по названию...» ищет по названию эпизода без учёта регистра.
- **«Все проекты»** — показать эпизоды одного проекта.
- **«Все статусы»** — показать эпизоды с одним статусом.

Таблица показывает по 25 эпизодов на странице, эпизоды идут по номеру.

## Таблица эпизодов

| Колонка | Что показывает |
|---|---|
| «Эпизод» | Метка с номером (`EP01`) и название эпизода |
| «Проект» | Название проекта; щелчок открывает [карточку проекта](/projects/card) |
| «Сцены» | Сколько сцен в эпизоде |
| «Шоты» | Сколько шотов в эпизоде |
| «Прогресс» | Полоса и процент готовности |
| «Статус» | Значок статуса |
| (последняя) | Кнопка :icon{name="i-lucide-ellipsis"} — меню действий со строкой |

Прогресс эпизода считается автоматически как среднее прогресса его сцен, а прогресс сцены — как среднее прогресса её шотов.

Если эпизодов нет, таблица показывает «Эпизодов пока нет».

### Статусы эпизода

Статус ставится вручную — в форме эпизода или во вкладке «Эпизоды» карточки проекта. В фильтре и форме статусы называются так, как в первой колонке; значок в таблице может называться чуть иначе.

| Статус | Значок в таблице | Цвет | Что означает |
|---|---|---|---|
| «Не начато» | «Не начато» | серый | Работа не начата (статус нового эпизода) |
| «В работе» | «В работе» | серый | Идёт производство |
| «На проверке» | «На проверке» | серый | Материал на проверке |
| «На правках» | «На правках» | серый | Вносятся правки |
| «Утверждено» | «Согласовано» | серый | Материал утверждён |
| «Завершено» | «Завершён» | зелёный | Работа закончена |
| «Приостановлено» | «Приостановлен» | жёлтый | Работа на паузе |

## Кнопки и действия

| Кнопка / иконка | Что делает | Право |
|---|---|---|
| «Активные» / «Архив» | Переключает таблицу между рабочим списком и архивом | `production:view` |
| :icon{name="i-lucide-plus"} «Новый эпизод» | Открывает панель создания эпизода | `production:manage` |
| :icon{name="i-lucide-ellipsis"} | Открывает меню действий со строкой | `production:view` |
| :icon{name="i-lucide-pencil"} «Редактировать» | Открывает панель редактирования (только в виде «Активные») | `production:manage` |
| :icon{name="i-lucide-archive"} «Архивировать» | Убирает эпизод в архив (только в виде «Активные») | `production:manage` |
| :icon{name="i-lucide-archive-restore"} «Вернуть из архива» | Возвращает эпизод в рабочий список (только в виде «Архив») | `production:manage` |
| :icon{name="i-lucide-trash-2"} «Удалить» | Спрашивает подтверждение и удаляет эпизод | `production:manage` |

## Панель эпизода

Панель открывается справа. Заголовок — «Новый эпизод» или «Редактирование эпизода». Обязательные поля отмечены красной звёздочкой.

| Поле | Обязательное | Что вводить |
|---|---|---|
| «Проект» | да | Проект, к которому относится эпизод. Только при создании — потом проект не меняется |
| «Название» | да | До 200 символов |
| «Номер» | нет | Номер эпизода от 1 до 9999. Пусто — следующий свободный в проекте. Номер не может повторяться внутри проекта |
| «Длительность, сек» | нет | От 0 до 86 400 секунд |
| «Статус» | нет | По умолчанию «Не начато» |
| «Старт» | нет | Дата начала |
| «Срок» | нет | Дедлайн эпизода |
| «Описание» | нет | До 4000 символов |
| «Файлы» | нет | Фото, видео, аудио или документ до 1 ГБ каждый. Загрузятся сразу после сохранения |

Кнопки внизу панели: «Отмена» (или :kbd{value="Esc"}, или :icon{name="i-lucide-x"} в заголовке) закрывает панель без сохранения; «Создать» / «Сохранить» сохраняет эпизод.

- Если не заполнено обязательное поле, появится «Заполните обязательные поля: …».
- Если номер уже занят — «Эпизод N уже есть в этом проекте».
- Если эпизод сохранился, а файлы — нет, панель остаётся открытой с сообщением «Запись сохранена, но не загрузились файлы: …». Загрузку файлов можно прервать кнопкой «Отменить».

::note
Для загрузки файлов нужно право `document:manage`. Продюсер и Менеджер проекта по умолчанию его не имеют: эпизод у них сохранится, а файлы — нет.
::

## Архив и удаление

**Архивирование** обратимо: эпизод пропадает из вида «Активные» и появляется в виде «Архив», откуда его возвращают действием «Вернуть из архива».

**Удаление** спрашивает подтверждение в окне «Удаление»: «Удалить эпизод «…»?». После подтверждения эпизод пропадает из всех списков.

::warning
Удалённый эпизод через интерфейс не вернуть — для обратимого скрытия используйте архив. Эпизод, в котором ещё есть сцены, удалить нельзя: появится сообщение «В эпизоде ещё есть сцены: N. Сначала удалите их.»
::

Эпизоды также создаются, меняются и удаляются во вкладке «Эпизоды» [карточки проекта](/projects/card).
