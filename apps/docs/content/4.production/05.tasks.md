Раздел «Задачи» — рабочий список производственных задач: кто что делает, к какому сроку и в каком статусе. У раздела три вида:

- **Список** — таблица с фильтрами и быстрыми выборками, адрес `/tasks`;
- **Доска** — колонки по статусам, карточки можно перетаскивать, адрес `/tasks/board`;
- **Календарь задач** — сетка месяца с задачами на днях их дедлайнов, адрес `/tasks/calendar`.

Где в меню: **«Производство» → «Задачи»**. Доска и календарь открываются кнопками в шапке списка.

Свои задачи удобнее смотреть в разделе [Мои задачи](/work/my-tasks), а задачи конкретного шота — в [карточке шота](/production/shot-card).

![Список задач](/screenshots/tasks.png)

## Доступ

| Что можно | Право | По умолчанию есть у |
|---|---|---|
| Открыть раздел и видеть **свои** задачи (где вы исполнитель) | `task:view:own` | Владелец, Администратор, Продюсер, Менеджер проекта, Арт-директор, Художник, Финансы |
| Видеть **все** задачи студии | `task:view` | Владелец, Администратор, Продюсер, Менеджер проекта, Арт-директор |
| Создавать задачи и удалять их | `task:create` | Владелец, Администратор, Продюсер, Менеджер проекта |
| Менять статус, название, приоритет, дедлайн, оценку, описание; перетаскивать карточки на доске; архивировать | `task:update` | Владелец, Администратор, Продюсер, Менеджер проекта, Художник |
| Назначать исполнителя и снимать зависимости между задачами | `task:assign` | Владелец, Администратор, Продюсер, Менеджер проекта |

Права ролей студия может менять в настройках (кроме Владельца) — подробнее в разделе [Роли и права](/start/roles).

::note
Если у вас есть только `task:view:own` (по умолчанию так у Художника и Финансов), во всех трёх видах — в списке, на доске и в календаре — показываются **только задачи, где исполнитель вы**. Ограничение действует на сервере: чужую задачу по ссылке открыть не получится, панель покажет «Не удалось загрузить задачу».
::

Без права `task:create` кнопки «Новая задача» нет. Без `task:update` поля в панели задачи недоступны для правки, а карточки на доске не перетаскиваются.

## Список задач

### Шапка

- Над заголовком — подпись «Производство», заголовок — «Задачи».
- Под заголовком — сколько задач в текущей выборке, например «12 задач».
- Справа — кнопки **«Новая задача»**, **«Календарь»** и **«Доска»**.

### Быстрые выборки

Под шапкой — ряд кнопок-выборок. Выбранная выборка запоминается в адресе страницы (`?view=…`), поэтому ссылкой на неё можно поделиться.

| Выборка | Что показывает |
|---|---|
| «Все» | Все задачи, кроме архивных (выбрана по умолчанию) |
| «Мои» | Задачи, где исполнитель — вы |
| «Просроченные» | Задачи с прошедшим дедлайном, которые ещё не в статусе «Утверждена» или «Завершена» |
| «На согласовании» | Задачи в статусе «На проверке» |
| «Завершённые» | Задачи в статусе «Завершена» |
| «Архив» | Только архивированные задачи |

### Поиск и фильтры

Над таблицей — строка поиска «Поиск по названию...». Ищет по названию и описанию задачи без учёта регистра. Рядом три фильтра:

- «Все проекты» — задачи одного проекта;
- «Все исполнители» — задачи одного сотрудника;
- «Любой приоритет» — задачи с выбранным приоритетом.

Фильтры складываются с выбранной выборкой и тоже попадают в адрес страницы. Таблица показывает по 25 задач на странице, новые — сверху.

::note
Список сотрудников в фильтре «Все исполнители» загружается только при праве `team:view`. Без него фильтр останется пустым — но в этом случае вы и так видите только свои задачи.
::

### Колонки таблицы

| Колонка | Что показывает |
|---|---|
| «Задача» | Название задачи — щелчок открывает панель задачи. Под названием серым: стадия пайплайна, код шота (ссылка на шот) и :icon{name="i-lucide-link"} с числом задач, от которых эта зависит |
| «Проект» | Название проекта — ссылка на карточку проекта |
| «Исполнитель» | Имя и фамилия; если никто не назначен — «не назначен» |
| «Срок» | Дедлайн в формате ДД.ММ.ГГ или «—» |
| «Приоритет» | Цветной значок приоритета (см. ниже) |
| «Статус» | Значок статуса задачи (см. ниже) |
| (последняя) | Кнопка :icon{name="i-lucide-ellipsis"} — меню действий со строкой |

Просроченная задача (дедлайн прошёл, а статус не «Утверждена» и не «Завершена») выделяется красным: перед названием появляется красная точка, название и срок окрашены красным.

Если в выборке ничего нет, таблица показывает «Задач нет» (в архиве — «Архив пуст»).

### Меню строки

Кнопка :icon{name="i-lucide-ellipsis"} в конце строки открывает меню:

| Пункт | Что делает |
|---|---|
| :icon{name="i-lucide-pencil"} «Редактировать» | Открывает панель задачи |
| :icon{name="i-lucide-archive"} «Архивировать» | Сразу переносит задачу в архив, без подтверждения |
| :icon{name="i-lucide-archive-restore"} «Вернуть из архива» | Возвращает задачу в работу (только в выборке «Архив») |
| :icon{name="i-lucide-trash-2"} «Удалить» | Спрашивает подтверждение «Удалить задачу «…»?» и удаляет задачу |

Пункты меню видны при праве `task:update`. Без него в меню написано «Недостаточно прав». Само удаление сервер выполняет только при праве `task:create`.

## Доска задач

Доска открывается кнопкой **«Доска»** в шапке списка, адрес `/tasks/board`. Заголовок — «Доска задач», под ним — число задач и подсказка «перетаскивайте карточки между колонками» (подсказка видна только при праве `task:update`).

![Доска задач](/screenshots/tasks-board.png)

Справа в шапке — фильтр **«Все проекты»** и кнопка **«Список»**, которая возвращает к таблице. Выбранный проект запоминается в адресе (`?projectId=…`).

### Колонки

Колонок семь, по статусам задачи: «Бэклог», «Готова к работе», «В работе», «На проверке», «На правках», «Утверждена», «Завершена». Рядом с названием колонки — число карточек в ней. Пустая колонка показывает «Пусто».

::note
Статус «Заблокирована» — не колонка: задачи в этом статусе на доске не показываются. Найти их можно в списке задач.
::

Щелчок по **заголовку колонки** открывает панель со всеми задачами этого статуса (с учётом выбранного проекта).

### Карточка задачи

На карточке:

- название задачи;
- проект (ссылка на карточку проекта), код шота (ссылка на шот) и :icon{name="i-lucide-link"} с числом зависимостей;
- исполнитель или «не назначен»;
- дедлайн справа внизу.

Просроченная карточка обведена красной рамкой, её дедлайн — красный. Щелчок по карточке открывает панель задачи.

### Перетаскивание

Чтобы сменить статус, перетащите карточку в другую колонку. Это то же самое, что смена статуса в панели задачи, и проходит те же проверки. В обсуждение задачи автоматически записывается комментарий «Перенесено на доске: …» со старым и новым статусом.

Если перенос не удался, над колонками появляется красное сообщение с причиной, например:

- «Сначала нужно закончить задачи-предшественники: …» — задача зависит от других, которые ещё не «Утверждена» и не «Завершена». Так бывает при переносе в «В работе», «На проверке», «На правках», «Утверждена» или «Завершена»;
- «Задача просрочена. Укажите причину переноса — она уйдёт администрации.» — просроченную задачу на доске можно перенести только в «Утверждена» или «Завершена». Для любого другого статуса откройте задачу и смените статус в панели.

::warning
Доска загружает не больше 100 задач. Если их больше, под заголовком появляется предупреждение «Показаны первые 100 задач — сузьте выборку фильтром по проекту». Полный состав колонки всегда виден в панели, которая открывается щелчком по её заголовку.
::

### Панель колонки

Открывается щелчком по заголовку колонки. Вверху — значок статуса и число задач, под ними — сводка: «N просрочено», «N без исполнителя» или «все задачи назначены и в срок».

Для каждой задачи показаны точка приоритета, название (щелчок открывает задачу), проект, шот, исполнитель и дедлайн. При праве `task:update` под каждой задачей есть выпадающий список статусов — выбор нового статуса сразу переносит задачу; в обсуждение пишется комментарий «Перенесено из панели статуса: …».

## Календарь задач

Открывается кнопкой **«Календарь»** в шапке списка, адрес `/tasks/calendar`. Заголовок — «Календарь дедлайнов», под ним — сколько задач с дедлайном и сколько «без даты».

![Календарь задач](/screenshots/tasks-calendar.png)

Справа в шапке — кнопки **«Список»** и **«Доска»** для перехода к другим видам.

### Управление месяцем и фильтры

- :icon{name="i-lucide-chevron-left"} и :icon{name="i-lucide-chevron-right"} — предыдущий и следующий месяц;
- **«Сегодня»** — вернуться к текущему месяцу;
- рядом — название месяца и год.

Справа — фильтры «Все проекты», «Все исполнители», «Любой приоритет». Месяц и фильтры запоминаются в адресе страницы.

### Сетка

Сетка — шесть недель, неделя начинается с понедельника. Сегодняшнее число выделено кружком. В ячейке дня — число задач с дедлайном на этот день и до трёх задач; если их больше — строка «ещё N».

Перед названием задачи — цветная точка приоритета:

| Точка | Приоритет |
|---|---|
| красная | «Срочный» |
| жёлтая | «Высокий» |
| основного цвета | «Обычный» |
| серая | «Низкий» |

Просроченная задача написана красным. Щелчок по задаче открывает её панель, щелчок по свободному месту ячейки — панель дня со всеми задачами этой даты (с учётом фильтров календаря). Пустые дни не нажимаются.

::note
Календарь строится по тем же первым 100 задачам, что и доска. Если задач больше, сузьте выборку фильтрами.
::

## Создание задачи

Кнопка **«Новая задача»** в шапке списка открывает панель «Новая задача». Под заголовком — напоминание «Исполнитель получит уведомление о назначении».

![Создание задачи](/screenshots/task-dialog.png)

| Поле | Обязательное | Что вводить |
|---|---|---|
| «Название» | да | От 2 до 200 символов |
| «Проект» | да | Проект, к которому относится задача |
| «Стадия пайплайна» | нет | Стадия выбранного проекта; по умолчанию «Без стадии». Доступно после выбора проекта |
| «Шот» | нет | Шот выбранного проекта; по умолчанию «Без привязки к шоту». Доступно после выбора проекта |
| «Исполнитель» | нет | Сотрудник; по умолчанию «Не назначен» |
| «Проверяющий» | нет | Только сотрудники с ролью Арт-директор, Менеджер проекта, Продюсер, Администратор или Владелец |
| «Оценка, часов» | нет | Число от 0 до 10 000, шаг 0,5 |
| «Статус» | нет | По умолчанию «Бэклог» |
| «Приоритет» | нет | По умолчанию «Обычный» |
| «Начало» | нет | Дата начала |
| «Дедлайн» | нет | Срок сдачи |
| «Описание» | нет | До 4000 символов |

При смене проекта выбранные стадия и шот сбрасываются — они принадлежат конкретному проекту.

Кнопка **«Создать задачу»** становится активной, когда заполнены название (не короче 2 символов) и проект. После создания список обновляется, а исполнитель получает уведомление о назначении. Кнопка «Отмена», :icon{name="i-lucide-x"} или клавиша :kbd{value="Esc"} закрывают панель без сохранения.

## Панель задачи

Открывается щелчком по названию задачи в списке, по карточке на доске, по задаче в календаре или в панелях колонки и дня. Панели открываются поверх друг друга: :kbd{value="Esc"} закрывает верхнюю, щелчок по затемнённому фону — все сразу.

В шапке панели — ссылки на проект и шот задачи, справа — :icon{name="i-lucide-x"} «Закрыть».

### Поля

| Поле | Как меняется | Право |
|---|---|---|
| Название | Прямо в заголовке панели, до 200 символов | `task:update` |
| :icon{name="i-lucide-circle-dot"} «Статус» | Выпадающий список, сохраняется сразу (см. ниже) | `task:update` |
| :icon{name="i-lucide-user"} «Исполнитель» | Выпадающий список, под ним — «Исполнитель получит уведомление о назначении» | `task:assign` |
| :icon{name="i-lucide-flag"} «Приоритет» | Выпадающий список | `task:update` |
| :icon{name="i-lucide-calendar"} «Дедлайн» | Дата | `task:update` |
| :icon{name="i-lucide-clock"} «Оценка, ч» | Число, шаг 0,5 | `task:update` |
| :icon{name="i-lucide-git-branch"} «Стадия» | Только просмотр, если стадия задана | — |
| «Описание» | Текстовое поле | `task:update` |

Ниже полей — блок «Вложения» (фото, видео, аудио, кнопка «Прикрепить»), блок «Обсуждение» с комментариями и, если есть, список «Зависит от» — задачи, которые нужно закончить раньше этой.

### Сохранение изменений

Все поля, кроме статуса, правятся в черновике. Как только что-то изменено, внизу появляется полоса «Есть несохранённые изменения» с кнопками **«Отменить»** (вернуть как было) и **«Сохранить»**. Сохраняются только изменённые поля, одним запросом.

Если вы сменили исполнителя, новый исполнитель получает уведомление о назначении.

### Смена статуса

Под выпадающим списком статуса — поле «Что сделано — обязательно для смены статуса». Сначала напишите в нём, что сделано (не короче 3 символов), затем выберите новый статус. Запись попадёт в обсуждение задачи. Без неё сервер откажет: «Приложите файл или опишите, что сделано».

Правила смены статуса:

- Переход в «В работе», «На проверке», «На правках», «Утверждена» или «Завершена» невозможен, пока задачи из списка «Зависит от» не в статусе «Утверждена» или «Завершена». Сообщение: «Сначала нужно закончить задачи-предшественники: …».
- При первом переходе в рабочий статус, если дата начала не задана, она проставляется автоматически.

### Просроченная задача

Если дедлайн прошёл, а задача не «Утверждена» и не «Завершена», вверху панели появляется красный блок :icon{name="i-lucide-clock-alert"} «Просрочена на N дн» с пояснением.

::warning
Любое изменение просроченной задачи уходит уведомлением администрации и требует причины. При сохранении полей рядом с кнопкой «Сохранить» появляется поле «Причина правки просроченной задачи» — без причины (не короче 3 символов) кнопка неактивна. Переводить просроченную задачу без причины можно только в «Утверждена» или «Завершена».
::

### Зависимости

В блоке «Зависит от» у каждой задачи-предшественницы — значок её статуса и название. Кнопка :icon{name="i-lucide-x"} снимает зависимость (нужно право `task:assign`).

### Архив и удаление

Внизу панели:

| Кнопка | Что делает | Право |
|---|---|---|
| :icon{name="i-lucide-archive"} «В архив» | Спрашивает «Архивировать задачу?» и убирает задачу из активных списков и доски. Все данные сохраняются | `task:update` |
| :icon{name="i-lucide-archive-restore"} «Вернуть из архива» | Возвращает архивную задачу в работу | `task:update` |
| :icon{name="i-lucide-trash-2"} «Удалить» | Спрашивает «Удалить задачу?» и удаляет задачу вместе с её зависимостями и связями | `task:create` |

::tip
Если задача просто больше не нужна в работе, используйте архив — его можно отменить в любой момент.
::

::warning
Удалённую задачу вернуть через интерфейс нельзя.
::

## Статусы задачи

| Статус | Что означает |
|---|---|
| «Бэклог» | Задача заведена, но ещё не готова к работе (значение по умолчанию) |
| «Готова к работе» | Можно начинать |
| «В работе» | Исполнитель работает над задачей |
| «На проверке» | Результат отправлен на проверку; в выборке «На согласовании» |
| «На правках» | Проверка вернула задачу на доработку |
| «Утверждена» | Результат принят (в значке статуса в таблице может отображаться как «Согласовано») |
| «Завершена» | Работа закончена; в выборке «Завершённые» |
| «Заблокирована» | Работа остановлена; на доске такие задачи не показываются |

«Утверждена» и «Завершена» — конечные статусы: такие задачи не считаются просроченными и не блокируют зависящие от них задачи.

Статусы задачи в таблице показываются серыми значками.

## Приоритеты

| Значок | Цвет | Что означает |
|---|---|---|
| «Низкий» | зелёный | Можно делать, когда освободится время |
| «Обычный» | синий | Значение по умолчанию |
| «Высокий» | жёлтый | Сделать в первую очередь |
| «Срочный» | красный | Требует немедленного внимания |
