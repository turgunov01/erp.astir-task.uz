Раздел «Шоты» показывает шоты всех проектов в одной таблице. Шот — основная производственная единица: у каждого шота свой набор стадий пайплайна, по которым считается его прогресс.

Где в меню: **«Производство» → «Шоты»**, адрес `/shots`.

![Список шотов](/screenshots/shots.png)

## Доступ

| Что можно | Право | По умолчанию есть у |
|---|---|---|
| Открыть раздел, список и карточки шотов | `production:view` | Владелец, Администратор, Продюсер, Менеджер проекта, Арт-директор, Художник |
| Создавать, редактировать, архивировать и удалять шоты | `production:manage` | Владелец, Администратор, Продюсер, Менеджер проекта |
| Прикреплять файлы в форме шота | `document:manage` | Владелец, Администратор, Финансы |

Права ролей студия может менять в настройках (кроме Владельца) — подробнее в разделе [Роли и права](/start/roles).

Без права `production:manage` кнопки «Новый шот» нет, а в меню строки вместо действий написано «Недостаточно прав».

## Шапка страницы

- Над заголовком — подпись «Производство», заголовок — «Шоты», под ним — например «120 шотов во всех проектах».
- Справа — переключатель **«Активные» / «Архив»** и кнопка **«Новый шот»**.

## Поиск и фильтры

- Строка поиска «Поиск по коду или названию...» ищет по коду и названию шота без учёта регистра.
- **«Все проекты»** — показать шоты одного проекта.
- **«Все статусы»** — показать шоты с одним статусом.

Поиск, фильтры и номер страницы сохраняются в адресе, поэтому отфильтрованный список можно отправить ссылкой. Таблица показывает по 25 шотов на странице.

## Таблица шотов

| Колонка | Что показывает |
|---|---|
| «Шот» | Код шота (щелчок открывает [карточку шота](/production/shot-card)), под ним — частота кадров и число версий, например «24 fps · 3 версии» |
| «Проект» | Название проекта; щелчок открывает [карточку проекта](/projects/card) |
| «Сцена» | Название сцены или «—» |
| «Исполнитель» | Ответственный за шот или «не назначен» |
| «Прогресс» | Полоса и процент готовности |
| «Статус» | Значок статуса |
| (последняя) | Кнопка :icon{name="i-lucide-ellipsis"} — меню действий со строкой |

Если шотов нет, таблица показывает «Шотов пока нет».

### Код шота

Код собирается автоматически из номеров эпизода, сцены и шота: `EP01_SC03_SH014`. Если шот не входит в эпизод, часть `EP` пропускается (`SC03_SH014`), если и сцены нет — остаётся только `SH014`. Код уникален внутри проекта.

### Статусы шота

| Статус | Значок в таблице | Цвет | Что означает |
|---|---|---|---|
| «Не начато» | «Не начато» | серый | Работа не начата (статус нового шота) |
| «В работе» | «В работе» | серый | Идёт производство |
| «На проверке» | «На проверке» | серый | Материал на проверке |
| «На правках» | «На правках» | серый | Вносятся правки |
| «Утверждено» | «Согласовано» | серый | Материал утверждён |
| «Завершено» | «Завершён» | зелёный | Все стадии шота завершены |
| «Приостановлено» | «Приостановлен» | жёлтый | Работа на паузе |

Статус меняется вручную в форме шота. Когда все стадии шота переведены в «Завершён», шот сам получает статус «Завершено».

## Стадии пайплайна и прогресс

При создании шот получает по одной стадии на каждую стадию пайплайна своего проекта. Состав зависит от шаблона, выбранного при [создании проекта](/projects/create). Полный пайплайн по умолчанию и вес стадий:

| № | Стадия | Вес | Отдел |
|---|---|---|---|
| 1 | Бриф | 1 | Руководство |
| 2 | Сценарий | 1 | Руководство |
| 3 | Раскадровка | 2 | 2D |
| 4 | Аниматик | 2 | 2D |
| 5 | Концепт-арт | 2 | 2D |
| 6 | Дизайн персонажей | 2 | 2D |
| 7 | Дизайн окружения | 2 | 2D |
| 8 | Моделинг | 3 | Моделинг |
| 9 | Риггинг | 3 | Риггинг |
| 10 | Лейаут | 2 | 3D |
| 11 | Анимация | 5 | Анимация |
| 12 | Симуляции и FX | 3 | 3D |
| 13 | Свет | 3 | Свет |
| 14 | Рендер | 4 | Рендер |
| 15 | Композитинг | 3 | Композитинг |
| 16 | Звук | 2 | Звук |
| 17 | Монтаж | 2 | Монтаж |
| 18 | Внутренний просмотр | 1 | Продакшн |
| 19 | Просмотр клиентом | 1 | Продакшн |
| 20 | Правки | 2 | Продакшн |
| 21 | Финальный рендер | 2 | Рендер |
| 22 | Сдача | 1 | Продакшн |

Прогресс шота — средневзвешенный прогресс его стадий: чем больше вес, тем сильнее стадия влияет на итог; завершённая стадия считается как 100%. Изменение стадии шота сразу пересчитывает прогресс шота, затем его сцены (среднее по шотам) и эпизода (среднее по сценам). Стадии шота меняются в [карточке шота](/production/shot-card).

::note
Если шот создан, когда у проекта ещё не было стадий, у шота их не будет — в карточке появится «Стадии не назначены».
::

| Кнопка / иконка | Что делает | Право |
|---|---|---|
| «Активные» / «Архив» | Переключает таблицу между рабочим списком и архивом | `production:view` |
| :icon{name="i-lucide-plus"} «Новый шот» | Открывает панель создания шота | `production:manage` |
| :icon{name="i-lucide-ellipsis"} | Открывает меню действий со строкой | `production:view` |
| :icon{name="i-lucide-pencil"} «Редактировать» | Открывает панель редактирования (только в виде «Активные») | `production:manage` |
| :icon{name="i-lucide-archive"} «Архивировать» | Убирает шот в архив (только в виде «Активные») | `production:manage` |
| :icon{name="i-lucide-archive-restore"} «Вернуть из архива» | Возвращает шот в рабочий список (только в виде «Архив») | `production:manage` |
| :icon{name="i-lucide-trash-2"} «Удалить» | Спрашивает подтверждение и удаляет шот | `production:manage` |

## Панель шота

Панель открывается справа. Заголовок — «Новый шот» или «Редактирование шота». Обязательные поля отмечены красной звёздочкой.

| Поле | Обязательное | Что вводить |
|---|---|---|
| «Проект» | да | Проект шота. Только при создании — потом проект не меняется |
| «Сцена» | нет | Сцена шота; эпизод шот берёт от сцены |
| «Название» | нет | До 200 символов |
| «Номер» | нет | От 1 до 9999. Пусто — следующий свободный в сцене. Если такой код уже есть в проекте — «Шот … уже есть в этом проекте» |
| «Кадров в секунду» | нет | От 1 до 240, по умолчанию 24 |
| «Первый кадр» | нет | Целое число от 0 |
| «Последний кадр» | нет | Целое число от 0 |
| «Длительность, сек» | нет | От 0 до 86 400 секунд |
| «Исполнитель» | нет | Ответственный сотрудник |
| «Статус» | нет | По умолчанию «Не начато» |
| «Срок» | нет | Дедлайн шота |
| «Описание» | нет | До 4000 символов; показывается в карточке шота |
| «Файлы» | нет | Фото, видео, аудио или документ до 1 ГБ каждый. Загрузятся сразу после сохранения |

Кнопки внизу панели: «Отмена» (или :kbd{value="Esc"}) закрывает панель без сохранения; «Создать» / «Сохранить» сохраняет шот. Если шот сохранился, а файлы — нет, панель остаётся открытой с сообщением «Запись сохранена, но не загрузились файлы: …».

::tip
Чтобы создать сразу много шотов в одной сцене, используйте кнопку «Шоты» во вкладке «Шоты» [карточки проекта](/projects/card): там можно создать до 50 шотов за раз.
::

## Архив и удаление

**Архивирование** обратимо: шот пропадает из вида «Активные» и появляется в виде «Архив», откуда его возвращают действием «Вернуть из архива».

**Удаление** спрашивает подтверждение в окне «Удаление»: «Удалить шот «…»?». После подтверждения шот пропадает из всех списков, а прогресс его сцены, эпизода и проекта пересчитывается.

::warning
Удалённый шот через интерфейс не вернуть — для обратимого скрытия используйте архив.
::
