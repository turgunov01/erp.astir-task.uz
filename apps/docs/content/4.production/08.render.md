Раздел «Очередь рендера» показывает задания на рендер шотов: что стоит в очереди, что считается сейчас, что готово и что упало с ошибкой. Над таблицей — состояние узлов рендер-фермы.

Где в меню: **«Производство» → «Очередь рендера»**, адрес `/render`.

![Очередь рендера](/screenshots/render.png)

## Доступ

| Что можно | Право | По умолчанию есть у |
|---|---|---|
| Открыть раздел и видеть задания и узлы | `render:view` | Владелец, Администратор, Продюсер, Менеджер проекта |
| Ставить задания, менять статус, редактировать, архивировать и удалять | `render:manage` | Владелец, Администратор, Продюсер |

Права ролей студия может менять в настройках (кроме Владельца) — подробнее в разделе [Роли и права](/start/roles).

Без права `render:manage` кнопки «Новое задание» нет, статус в таблице показывается значком, а в меню строки написано «Недостаточно прав».

## Шапка страницы

- Над заголовком — подпись «Производство», заголовок — «Очередь рендера».
- Под заголовком — сводка «N в очереди · N рендерится · N с ошибкой». Если есть задания с ошибкой, последняя часть сводки красная.

## Узлы рендер-фермы

Под шапкой — плитки узлов. На каждой:

- название узла;
- точка справа: зелёная — узел в сети, серая — не в сети;
- строка «N заданий · в сети» или «N заданий · не в сети».

## Выборки

Ряд кнопок над таблицей; рядом с выборками по статусу — число заданий. Выбранная выборка запоминается в адресе (`?view=…`).

| Выборка | Что показывает |
|---|---|
| «В очереди» | Задания, ожидающие запуска |
| «Рендерится» | Задания, которые считаются сейчас |
| «Готово» | Завершённые задания |
| «Ошибки» | Задания, упавшие с ошибкой |
| «Все» | Все задания (выбрана по умолчанию) |

Справа над таблицей — переключатель **«Активные» / «Архив»** и кнопка **«Новое задание»**.

## Таблица

В строке поиска написано «Поиск недоступен в этом разделе». Таблица показывает по 25 заданий на странице.

| Колонка | Что показывает |
|---|---|
| «Шот» | Код шота — ссылка на шот. Если задание упало, под кодом красным — текст ошибки |
| «Проект» | Ссылка на карточку проекта |
| «Кадры» | Диапазон и число кадров, например «1001–1100 (100)», или «—» |
| «Узел» | Узел, на котором идёт рендер, или «не назначен» |
| «Прогресс» | Полоса прогресса |
| «Статус» | Выпадающий список статусов (при праве `render:manage`) или значок |
| (последняя) | Кнопка :icon{name="i-lucide-ellipsis"} — меню действий |

Выбор нового статуса в колонке «Статус» сохраняется сразу. Что происходит при смене статуса:

- «Рендерится» — при первом запуске запоминается время старта;
- «Готово» — запоминается время завершения, прогресс становится 100 %;
- «Ошибка» — тот, кто поставил задание, получает уведомление о неудачном рендере.

Если сохранить не удалось, над таблицей появляется «Не удалось обновить задание». Если заданий нет — «Очередь пуста».

## Панель задания

Щелчок по строке открывает панель задания: заголовок — код шота, подзаголовок — «Очередь рендера».

- Вверху — значок статуса и приоритет.
- «Прогресс» — процент и полоса (красная, если задание упало).
- «Ошибка рендера» — текст ошибки, если он есть.
- Сведения: «Статус», «Проект», «Шот», «Версия» (с кнопкой открыть файл версии), «Узел» (с пометкой «онлайн» / «офлайн»), «Кадры», «Поставил», «Начат», «Завершён», «Длительность», «Создан».

## Создание и редактирование задания

Кнопка **«Новое задание»** открывает форму «Новое задание рендера». Пункт «Редактировать» в меню строки открывает «Редактирование задания».

| Поле | Обязательное | Когда доступно | Что вводить |
|---|---|---|---|
| «Проект» | да | при создании | Проект |
| «Шот» | нет | при создании | Шот для рендера |
| «Первый кадр» | нет | при создании | Целое число от 0 |
| «Последний кадр» | нет | при создании | Целое число от 0 |
| «Приоритет» | нет | всегда | «Низкий», «Обычный», «Высокий», «Срочный»; по умолчанию «Обычный» |
| «Статус» | нет | при редактировании | Статус задания |
| «Прогресс, %» | нет | при редактировании | Целое число от 0 до 100 |
| «Узел» | нет | при редактировании | Узел рендер-фермы |
| «Текст ошибки» | нет | при редактировании | До 2000 символов |
| «Файлы» | нет | всегда | Фото, видео, аудио или документ — загрузятся сразу после сохранения |

Новое задание всегда попадает в очередь со статусом «В очереди»; автором («Поставил») записывается тот, кто его создал.

## Статусы задания

| Значок | Цвет | Что означает |
|---|---|---|
| «В очереди» | серый | Ожидает запуска |
| «Рендерится» | серый | Считается |
| «Готово» | зелёный | Рендер завершён (в значке может отображаться как «Завершён») |
| «Ошибка» | серый | Рендер упал; причина — в тексте ошибки |
| «Отменено» | красный | Задание отменено (в значке может отображаться как «Отменён») |

## Кнопки и действия

| Кнопка / иконка | Что делает | Право |
|---|---|---|
| Выборки «В очереди» … «Все» | Меняют набор заданий | `render:view` |
| «Активные» / «Архив» | Переключает таблицу между рабочим списком и архивом | `render:view` |
| :icon{name="i-lucide-plus"} «Новое задание» | Открывает форму нового задания | `render:manage` |
| Выпадающий список в колонке «Статус» | Сразу меняет статус задания | `render:manage` |
| :icon{name="i-lucide-ellipsis"} → :icon{name="i-lucide-pencil"} «Редактировать» | Открывает форму редактирования | `render:manage` |
| :icon{name="i-lucide-ellipsis"} → :icon{name="i-lucide-archive"} «Архивировать» | Сразу переносит задание в архив | `render:manage` |
| :icon{name="i-lucide-ellipsis"} → :icon{name="i-lucide-archive-restore"} «Вернуть из архива» | Возвращает задание из архива | `render:manage` |
| :icon{name="i-lucide-ellipsis"} → :icon{name="i-lucide-trash-2"} «Удалить» | После подтверждения удаляет задание | `render:manage` |

::warning
Удалённое задание вернуть через интерфейс нельзя. Для обратимого скрытия используйте архив.
::
