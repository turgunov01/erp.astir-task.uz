Раздел «Согласование» собирает версии работ, вынесенные на обсуждение: внутри студии или с клиентом. Здесь смотрят присланный материал, обсуждают его и принимают решение — согласовать, вернуть на доработку или отклонить.

Где в меню: **«Производство» → «Согласование»**, адрес `/reviews`.

![Согласование](/screenshots/reviews.png)

## Доступ

| Что можно | Право | По умолчанию есть у |
|---|---|---|
| Открыть раздел, смотреть согласования, писать в обсуждение | `review:view` | Владелец, Администратор, Продюсер, Менеджер проекта, Арт-директор, Художник, Клиент |
| Отправлять версии на согласование, менять настройки, архивировать и удалять согласования | `review:internal` | Владелец, Администратор, Продюсер, Менеджер проекта, Арт-директор |

Права ролей студия может менять в настройках (кроме Владельца) — подробнее в разделе [Роли и права](/start/roles).

Кто может принять решение, зависит от типа согласования, а не только от прав:

| Тип согласования | Кто видит кнопки решения |
|---|---|
| «Клиентское» | Клиент, Владелец, Администратор |
| Любой другой («Внутреннее», «Арт-директор», «Финальное») | Любой пользователь раздела, кроме Клиента |

::note
Клиент видит в списке только клиентские согласования — внутренние обсуждения студии ему не показываются.
::

Без права `review:internal` кнопки «На согласование» нет, а в меню строки вместо действий написано «Недостаточно прав».

## Шапка страницы

- Над заголовком — подпись «Производство», заголовок — «Согласование».
- Под заголовком — сводка «N в работе · N на доработке · N согласовано».

## Выборки

Ряд кнопок под шапкой. Рядом с выборками по статусу — число согласований в этом статусе. Выбранная выборка запоминается в адресе страницы (`?view=…`).

| Выборка | Что показывает |
|---|---|
| «Ожидают» | Статус «Ожидает» — согласование создано, обсуждение ещё не началось |
| «В работе» | Статус «На обсуждении» (выбрана по умолчанию) |
| «Внутренние» | Все согласования типа «Внутреннее» |
| «Клиентские» | Все согласования типа «Клиентское» |
| «На доработке» | Статус «Нужны правки» |
| «Согласованы» | Статус «Согласовано» |
| «Все» | Все согласования, включая отклонённые и закрытые по сроку |

Справа над таблицей — переключатель **«Активные» / «Архив»** и кнопка **«На согласование»**.

## Таблица

В строке поиска написано «Поиск недоступен в этом разделе» — набор сужается выборками и фильтром **«Все проекты»** рядом. Таблица показывает по 25 строк на странице.

| Колонка | Что показывает |
|---|---|
| «Версия» | Название версии. Под ним — код шота и, пока решения нет, сколько ждёт: «ждёт сегодня» или «ждёт N дн» |
| «Проект» | Ссылка на карточку проекта |
| «Тип» | «Внутреннее», «Арт-директор», «Клиентское» или «Финальное» |
| «Автор» | Кто загрузил версию |
| «Проверяющий» | Назначенный проверяющий или «не назначен» |
| «Статус» | Значок статуса согласования |
| (последняя) | Кнопка :icon{name="i-lucide-ellipsis"} — меню действий |

Щелчок по строке открывает панель согласования. Если согласований нет — «Нет согласований».

## Панель согласования

В шапке — тип («Внутреннее согласование», «Клиентское согласование» и т. п.), название версии и значок статуса; :icon{name="i-lucide-x"} закрывает панель.

### Материал

Вверху — превью версии: картинка или видеоплеер. Кнопка :icon{name="i-lucide-maximize-2"} **«На весь экран»** открывает материал в полноэкранном просмотре (для других типов файлов кнопка называется «Открыть файл»). Если файла нет — «Превью недоступно · файл не загружен».

### Сведения

| Поле | Что показывает |
|---|---|
| «Проект» | Ссылка на проект |
| «Шот» | Ссылка на шот (если версия привязана к шоту) |
| «Задача» | Задача версии — щелчок открывает панель задачи |
| «Автор версии» | Кто загрузил версию |
| «Проверяющий» | Назначенный проверяющий или «не назначен» |
| «Срок обсуждения» | «без срока», «ДД.ММ.ГГ · осталось N дн.», «… · сегодня последний день» или «… · срок прошёл» |
| «Отправлено» | Дата создания согласования |

Ниже — «Комментарий» (текст, с которым версию отправили или вернули), «Материалы обсуждения» — фото, видео или аудио к обсуждению (прикреплять можно, пока согласование не завершено) — и «Обсуждение» с комментариями.

### Решение

Внизу панели, если вам доступно решение (см. «Доступ») и согласование ещё не завершено:

1. Поле комментария — «Комментарий — обязателен при возврате на доработку».
2. Поле даты «Дедлайн правок» — срок для правки, которая создаётся при возврате на доработку.
3. Кнопки решения:

| Кнопка | Что происходит |
|---|---|
| «Согласовать» | Согласование и версия получают статус «Согласовано». Прежние отправленные и согласованные версии того же шота становятся «Заменена новой». Задача версии переходит в «Утверждена» |
| «На доработку» | Нужен комментарий — без него сервер ответит «Опишите, что нужно исправить». Согласование получает статус «Нужны правки», создаётся [правка](/production/revisions) «Правки по <код шота>» со следующим номером раунда, комментарием в описании и сроком из «Дедлайн правок»; исполнитель правки — автор версии. Задача версии переходит в «На правках» |
| «Отклонить» | Согласование и версия получают статус «Отклонено» |

Автор версии получает уведомление о решении (если решение принял не он сам). Если в согласовании не был назначен проверяющий, им становится тот, кто принял решение.

После «Согласовать» или «Отклонить» вместо кнопок появляется строка «Согласование завершено ДД.ММ.ГГ». Принять другое решение по завершённому согласованию нельзя.

### Закрытие по сроку

Если у согласования задан «Срок обсуждения» и он прошёл, а согласование всё ещё «Ожидает» или «На обсуждении», оно получает статус «Вопрос закрыт». В панели появляется пояснение: решения до срока не было, поэтому вопрос закрыт.

::tip
Чтобы вернуть закрытое по сроку обсуждение, откройте меню строки → «Редактировать» и задайте новый «Срок обсуждения» в будущем. Согласование снова получит статус «Ожидает».
::

## Отправка на согласование

Кнопка **«На согласование»** открывает панель «Отправить на согласование». Через пункт «Редактировать» меню строки открывается та же форма под названием «Настройки согласования».

| Поле | Обязательное | Что вводить |
|---|---|---|
| «Версия» | да | Материал, который выносится на обсуждение. Только при создании |
| «Тип согласования» | нет | В списке четыре типа, но при создании сохраняются только «Внутреннее» и «Клиентское»; «Арт-директор» и «Финальное» можно выбрать при редактировании |
| «Проверяющий» | нет | Сотрудник; по умолчанию «Любой из команды» |
| «Срок обсуждения» | нет | Если до этой даты решения не будет, согласование получит статус «Вопрос закрыт» |
| «Что обсуждаем» | нет | Вопрос к обсуждению, на что смотреть в первую очередь; до 2000 символов |
| «Файлы» | нет | Фото, видео, аудио или документ — загрузятся сразу после сохранения |

Кнопка **«Создать»** (при редактировании — «Сохранить») сохраняет согласование. Новое согласование появляется в выборке «Ожидают».

## Статусы согласования

| Значок | Что означает |
|---|---|
| «Ожидает» | Согласование создано, обсуждение не началось |
| «На обсуждении» | Идёт обсуждение |
| «Нужны правки» | Версию вернули на доработку, создана правка |
| «Согласовано» | Версия принята |
| «Отклонено» | Версия отклонена |
| «Вопрос закрыт» | Срок обсуждения прошёл без решения |

Значки статусов согласования — серые; различаются они подписью.

## Кнопки и действия

| Кнопка / иконка | Что делает | Право |
|---|---|---|
| Выборки «Ожидают» … «Все» | Меняют набор согласований | `review:view` |
| «Все проекты» | Показывает согласования одного проекта | `review:view` |
| «Активные» / «Архив» | Переключает таблицу между рабочим списком и архивом | `review:view` |
| :icon{name="i-lucide-plus"} «На согласование» | Открывает форму отправки версии на согласование | `review:internal` |
| :icon{name="i-lucide-ellipsis"} → :icon{name="i-lucide-pencil"} «Редактировать» | Открывает «Настройки согласования» | `review:internal` |
| :icon{name="i-lucide-ellipsis"} → :icon{name="i-lucide-archive"} «Архивировать» | Сразу переносит согласование в архив | `review:internal` |
| :icon{name="i-lucide-ellipsis"} → :icon{name="i-lucide-archive-restore"} «Вернуть из архива» | Возвращает согласование из архива | `review:internal` |
| :icon{name="i-lucide-ellipsis"} → :icon{name="i-lucide-trash-2"} «Удалить» | После подтверждения удаляет согласование | `review:internal` |
| :icon{name="i-lucide-maximize-2"} «На весь экран» | Открывает материал версии в полноэкранном просмотре | `review:view` |
| «Согласовать» / «На доработку» / «Отклонить» | Решение по согласованию | см. «Доступ» |

::warning
Удалённое согласование вернуть через интерфейс нельзя. Чтобы просто убрать его из рабочего списка, используйте архив.
::
