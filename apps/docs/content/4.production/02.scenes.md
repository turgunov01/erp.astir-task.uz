Раздел «Сцены» показывает сцены всех проектов в одной таблице. Сцена группирует [шоты](/production/shots) внутри [эпизода](/production/episodes) и задаёт их нумерацию. Сцена может быть и без эпизода — например, в рекламном ролике.

Где в меню: **«Производство» → «Сцены»**, адрес `/scenes`.

![Список сцен](/screenshots/scenes.png)

## Доступ

| Что можно | Право | По умолчанию есть у |
|---|---|---|
| Открыть раздел и видеть список | `production:view` | Владелец, Администратор, Продюсер, Менеджер проекта, Арт-директор, Художник |
| Создавать, редактировать, архивировать и удалять сцены | `production:manage` | Владелец, Администратор, Продюсер, Менеджер проекта |
| Прикреплять файлы в форме сцены | `document:manage` | Владелец, Администратор, Финансы |

Права ролей студия может менять в настройках (кроме Владельца) — подробнее в разделе [Роли и права](/start/roles).

Без права `production:manage` кнопки «Новая сцена» нет, а в меню строки вместо действий написано «Недостаточно прав».

## Шапка страницы

- Над заголовком — подпись «Производство», заголовок — «Сцены», под ним — число сцен в выборке, например «14 сцен».
- Справа — переключатель **«Активные» / «Архив»** и кнопка **«Новая сцена»**.

## Поиск и фильтры

- Строка поиска «Поиск по названию...» ищет по названию сцены без учёта регистра.
- **«Все проекты»** — показать сцены одного проекта.
- **«Все статусы»** — показать сцены с одним статусом.

Таблица показывает по 25 сцен на странице. При переключении «Активные» / «Архив» таблица возвращается на первую страницу.

## Таблица сцен

| Колонка | Что показывает |
|---|---|
| «Сцена» | Метка `EP01_SC03` (у сцены без эпизода — `SC03`) и название сцены |
| «Проект» | Название проекта; щелчок открывает [карточку проекта](/projects/card) |
| «Эпизод» | Название эпизода или «без эпизода» |
| «Шоты» | Сколько шотов в сцене |
| «Прогресс» | Полоса и процент готовности — среднее прогресса шотов сцены |
| «Статус» | Значок статуса |
| (последняя) | Кнопка :icon{name="i-lucide-ellipsis"} — меню действий со строкой |

Если сцен нет, таблица показывает «Сцен пока нет».

### Статусы сцены

Статус ставится вручную — в форме сцены или во вкладке «Сцены» карточки проекта.

| Статус | Значок в таблице | Цвет | Что означает |
|---|---|---|---|
| «Не начато» | «Не начато» | серый | Работа не начата (статус новой сцены) |
| «В работе» | «В работе» | серый | Идёт производство |
| «На проверке» | «На проверке» | серый | Материал на проверке |
| «На правках» | «На правках» | серый | Вносятся правки |
| «Утверждено» | «Согласовано» | серый | Материал утверждён |
| «Завершено» | «Завершён» | зелёный | Работа закончена |
| «Приостановлено» | «Приостановлен» | жёлтый | Работа на паузе |

## Кнопки и действия

| Кнопка / иконка | Что делает | Право |
|---|---|---|
| «Активные» / «Архив» | Переключает таблицу между рабочим списком и архивом | `production:view` |
| :icon{name="i-lucide-plus"} «Новая сцена» | Открывает панель создания сцены | `production:manage` |
| :icon{name="i-lucide-ellipsis"} | Открывает меню действий со строкой | `production:view` |
| :icon{name="i-lucide-pencil"} «Редактировать» | Открывает панель редактирования (только в виде «Активные») | `production:manage` |
| :icon{name="i-lucide-archive"} «Архивировать» | Убирает сцену в архив (только в виде «Активные») | `production:manage` |
| :icon{name="i-lucide-archive-restore"} «Вернуть из архива» | Возвращает сцену в рабочий список (только в виде «Архив») | `production:manage` |
| :icon{name="i-lucide-trash-2"} «Удалить» | Спрашивает подтверждение и удаляет сцену | `production:manage` |

## Панель сцены

Панель открывается справа. Заголовок — «Новая сцена» или «Редактирование сцены». Обязательные поля отмечены красной звёздочкой.

| Поле | Обязательное | Что вводить |
|---|---|---|
| «Проект» | да | Проект сцены. Только при создании — потом проект не меняется |
| «Эпизод» | нет | Эпизод, в который входит сцена. Эпизод должен быть из того же проекта, иначе появится «Этот эпизод относится к другому проекту» |
| «Название» | да | До 200 символов |
| «Номер» | нет | От 1 до 9999. Пусто — следующий свободный номер в эпизоде. Номер не может повторяться («Сцена N здесь уже есть») |
| «Длительность, сек» | нет | От 0 до 86 400 секунд |
| «Статус» | нет | По умолчанию «Не начато» |
| «Описание» | нет | До 4000 символов |
| «Файлы» | нет | Фото, видео, аудио или документ до 1 ГБ каждый. Загрузятся сразу после сохранения |

Кнопки внизу панели: «Отмена» (или :kbd{value="Esc"}) закрывает панель без сохранения; «Создать» / «Сохранить» сохраняет сцену. Если сцена сохранилась, а файлы — нет, панель остаётся открытой с сообщением «Запись сохранена, но не загрузились файлы: …».

::note
В списке «Эпизод» показаны эпизоды всех проектов только по названию. Если названия совпадают, проверьте, что выбран эпизод нужного проекта, — удобнее создавать сцены во вкладке «Сцены» [карточки проекта](/projects/card), где список эпизодов уже ограничен проектом.
::

## Архив и удаление

**Архивирование** обратимо: сцена пропадает из вида «Активные» и появляется в виде «Архив», откуда её возвращают действием «Вернуть из архива».

**Удаление** спрашивает подтверждение в окне «Удаление»: «Удалить сцену «…»?». После подтверждения сцена пропадает из всех списков, прогресс её эпизода и проекта пересчитывается.

::warning
Удалённую сцену через интерфейс не вернуть — для обратимого скрытия используйте архив. Сцену, в которой ещё есть шоты, удалить нельзя: появится сообщение «В сцене ещё есть шоты: N. Сначала удалите их.»
::
