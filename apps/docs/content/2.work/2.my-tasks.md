«Мои задачи» — личный список всего, что назначено на вас. Пункт **«Мои задачи»** стоит в верхней части бокового меню, адрес — `/tasks/my`. Для большинства сотрудников именно с этой страницы начинается работа: после входа в систему она открывается автоматически (подробнее — в разделе [Панель управления](/work/dashboard), блок «Что открывается при входе»).

Под заголовком — подпись «{Имя}, здесь всё, что назначено на вас — сначала то, что горит.».

![Мои задачи](/screenshots/my-tasks.png)

## Доступ

Нужно право `task:view:own` (по умолчанию есть у: Владелец, Администратор, Продюсер, Менеджер проекта, Арт-директор, Художник, Финансы). У Клиента этого права нет.

На странице всегда только ваши задачи — те, где вы исполнитель, — даже если у вас есть право видеть все задачи студии. Чужие задачи смотрите в разделе [Задачи](/production/tasks).

Менять статус прямо из списка можно с правом `task:update` (по умолчанию: Владелец, Администратор, Продюсер, Менеджер проекта, Художник). Без него кнопки «Статус» нет, но задачу можно открыть и посмотреть.

Удалённые и архивные задачи в список не попадают.

## Кнопка «Учёт времени»

Справа от заголовка — кнопка :icon{name="i-lucide-clock"} «Учёт времени». Она открывает ваш [Табель](/team/timesheets) и видна при праве `timesheet:view:own`.

## Сводка

Четыре плитки над списком. Нажатие на плитку переключает список на соответствующую выборку.

| Плитка | Что считается | Куда переключает |
|---|---|---|
| :icon{name="i-lucide-alarm-clock"} «Просрочено» | открытые задачи, срок которых уже прошёл. Число и иконка становятся красными, если оно больше нуля | «Просроченные» |
| :icon{name="i-lucide-play"} «В работе и на правках» | задачи в статусах «В работе» и «На правках» (кроме просроченных) | «Открытые» |
| :icon{name="i-lucide-calendar-clock"} «Срок на этой неделе» | открытые задачи, срок которых наступает в ближайшие 7 дней и ещё не прошёл | «Открытые» |
| :icon{name="i-lucide-eye"} «На проверке» | задачи в статусе «На проверке» (кроме просроченных) | «На проверке» |

## Выборки

Под плитками — переключатель выборок. Рядом с каждой — число задач. Выбранная выборка сохраняется в адресе страницы (`?view=…`), поэтому ссылкой на неё можно поделиться.

| Выборка | Что показывает |
|---|---|
| «Открытые» | все незавершённые задачи, разложенные по разделам (см. ниже) |
| «Просроченные» | только раздел «Просрочено» |
| «На проверке» | только раздел «На проверке» |
| «Завершённые» | последние 25 задач в статусах «Завершена» и «Утверждена», самые свежие по сроку сверху |

## Разделы списка

В выборке «Открытые» задачи разложены по разделам в том порядке, в котором их стоит брать в работу. Каждая задача попадает в первый подходящий раздел, пустые разделы не показываются.

| Раздел | Какие задачи |
|---|---|
| :icon{name="i-lucide-alarm-clock"} «Просрочено» | срок прошёл (заголовок раздела выделен красным) |
| :icon{name="i-lucide-rotate-ccw"} «На правках» | статус «На правках» |
| :icon{name="i-lucide-play"} «В работе» | статус «В работе» |
| :icon{name="i-lucide-circle-dashed"} «К выполнению» | статусы «Бэклог» и «Готова к работе» |
| :icon{name="i-lucide-octagon-pause"} «Заблокировано» | статус «Заблокирована» |
| :icon{name="i-lucide-eye"} «На проверке» | статус «На проверке» |

Открытые задачи загружаются по сроку — сначала ближайшие, не больше 100 штук. Если задач больше, внизу появится строка «Показаны N из M — ближайшие по сроку.» со ссылкой «Весь список», которая открывает раздел [Задачи](/production/tasks) с выборкой ваших задач.

## Строка задачи

Каждая строка содержит:

- **Цветную точку слева**: красная — задача просрочена, оранжевая — срок сегодня, завтра или послезавтра, серая — в остальных случаях.
- **Название** — нажатие открывает панель задачи поверх списка (подробнее о ней — в разделе [Задачи](/production/tasks)). После закрытия панели список обновляется.
- **Под названием** — проект (ссылка на [карточку проекта](/projects/card)), код шота (ссылка на [карточку шота](/production/shot-card)) и этап, если они есть.
- **Срок** с иконкой :icon{name="i-lucide-calendar-clock"} — словами относительно сегодняшнего дня: «Сегодня», «Завтра», «Через N дн.», «Сегодня, срок прошёл», «Просрочено на N дн.» или «Без срока». У завершённых задач показывается дата. При наведении видна точная дата.
- **Приоритет** — только если он важен для очерёдности: «Высокий» (оранжевый) или «Срочный» (красный). Обычный и низкий приоритеты не показываются.
- **Статус** задачи.
- **Кнопка «Статус»** — быстрая смена статуса (см. ниже).

Статусы задач: «Бэклог», «Готова к работе», «В работе», «На проверке», «На правках», «Утверждена», «Завершена», «Заблокирована».

## Быстрая смена статуса

Кнопка :icon{name="i-lucide-arrow-right-left"} «Статус» раскрывает под задачей небольшую форму.

| Поле | Обязательное | Что вводить |
|---|---|---|
| «Новый статус» | да | Список всех статусов, кроме текущего. Заранее выбран самый частый следующий шаг: из «Бэклог» — «Готова к работе», из «Готова к работе» — «В работе», из «В работе» и «На правках» — «На проверке», из «На проверке» и «Заблокирована» — «В работе», из «Утверждена» — «Завершена», из «Завершена» — «В работе». |
| «Что сделано — попадёт в обсуждение задачи» | да | Комментарий от 3 до 4000 символов. |
| «Почему срок сорван — уйдёт администрации» | да, только для просроченной задачи | Причина просрочки, от 3 до 500 символов. Поле появляется, только если срок задачи уже прошёл. |

Кнопка «Сменить статус» становится активной, когда все обязательные поля заполнены. «Отмена» сворачивает форму без изменений.

После сохранения:

- статус задачи меняется, список обновляется;
- комментарий записывается в обсуждение задачи вместе с тем, из какого статуса в какой её перевели;
- событие попадает в [Ленту событий](/other/activity);
- если задача была просрочена, причина записывается в обсуждение задачи, а Владельцу и Администраторам приходит уведомление.

::warning
Задачу нельзя перевести в статусы «В работе», «На проверке», «На правках», «Утверждена» или «Завершена», пока не закончены задачи, от которых она зависит. В этом случае появится сообщение «Сначала нужно закончить задачи-предшественники: …».
::

## Кнопки

| Кнопка / иконка | Что делает | Право |
|---|---|---|
| :icon{name="i-lucide-clock"} «Учёт времени» | Открывает ваш Табель | `timesheet:view:own` |
| Плитки сводки | Переключают выборку | `task:view:own` |
| «Открытые», «Просроченные», «На проверке», «Завершённые» | Переключают выборку | `task:view:own` |
| Название задачи | Открывает панель задачи | `task:view:own` |
| :icon{name="i-lucide-arrow-right-left"} «Статус» | Открывает форму быстрой смены статуса | `task:update` |
| «Сменить статус» | Сохраняет новый статус и комментарий | `task:update` |
| «Отмена» | Закрывает форму без изменений | — |
| «Весь список» | Открывает раздел Задачи с вашими задачами | `task:view:own` |
| «Повторить» | Повторно загружает список после ошибки | `task:view:own` |

## Пустые списки

- «Открытые»: «Открытых задач нет. Новые появятся здесь, как только их назначат.»
- «Просроченные»: «Просроченных задач нет — так держать.»
- «На проверке»: «Сейчас ничего не ждёт проверки.»
- «Завершённые»: «Завершённых задач пока нет.»

::tip
Адрес вида `/tasks/my?task=<id задачи>` открывает страницу сразу с панелью этой задачи.
::
