Финансовый отчёт находится в меню **Отчёты → Финансы**, адрес `/reports/financial`. Заголовок страницы — «Финансы», в заголовке вкладки браузера — «Финансовый отчёт».

Отчёт показывает движение денег студии: сколько выставлено клиентам, сколько реально получено и сколько потрачено — помесячно, а также структуру расходов и долги клиентов по срокам.

![Финансовый отчёт](/screenshots/reports-financial.png)

## Доступ

Нужны два права: `report:view` и `finance:view` (по умолчанию оба есть у: Владелец, Администратор, Финансы). Роль, у которой есть только одно из них, пункта «Финансы» в группе «Отчёты» не видит.

## Фильтр периода

Поля «С» и «по» ограничивают период отчёта; пустые поля — всё время. Даты сохраняются в адресе страницы. Кнопка «Сбросить» очищает обе даты. Подробнее — на странице [Отчёты](/reports/overview).

Период влияет на итоговые карточки, таблицу «По месяцам» и «Расходы по категориям». На таблицу «Дебиторка по срокам» период **не влияет**.

## Предупреждение о нескольких валютах

Все суммы на странице складываются без пересчёта валют. Если в выбранном периоде у счетов, платежей или расходов встречается больше одной валюты, над карточками появляется жёлтое предупреждение со списком валют: «В выборке несколько валют (…). Итоги ниже складывают их как одну — сузьте период или разнесите валюты, прежде чем опираться на эти суммы.»

Суммы показываются в валюте, которая встретилась первой; если данных нет — в USD.

## Итоговые карточки

| Карточка | Как считается |
| --- | --- |
| «Выставлено» | Сумма всех счетов, дата выставления которых попадает в период |
| «Получено» | Сумма платежей в статусе «Оплачен», дата оплаты которых попадает в период |
| «Потрачено» | Сумма расходов, дата которых попадает в период |
| «Итого» | «Получено» минус «Потрачено». Красное, если меньше нуля |

::note
«Итого» считается от полученных денег, а не от выставленных: выставленный, но не оплаченный счёт на него не влияет.
::

## Таблица «По месяцам»

Одна строка на месяц, в котором было хоть какое-то движение денег; месяцы идут по порядку. Месяцы без счетов, платежей и расходов не показываются.

| Колонка | Как считается |
| --- | --- |
| «Месяц» | Месяц и год, например «окт. 2026» |
| «Выставлено» | Сумма счетов, выставленных в этом месяце (по дате выставления) |
| «Получено» | Сумма оплаченных платежей с датой оплаты в этом месяце |
| «Потрачено» | Сумма расходов с датой в этом месяце |
| «Итого» | «Получено» минус «Потрачено» за месяц. Красное, если меньше нуля |

Если за период движения денег не было, вместо таблицы — надпись «За выбранный период движения денег не было.»

## Таблица «Расходы по категориям»

Сумма расходов за период по каждой категории («Штат», «Подряд», «Рендер», «Софт», «Железо», «Звук», «Продакшн», «Аренда и офис», «Налоги и сборы», «Маркетинг», «Прочее»). Категории отсортированы по сумме — сначала самые крупные. Категории без расходов не показываются.

Если расходов за период нет — надпись «Расходов за период нет.»

## Таблица «Дебиторка по срокам»

Под заголовком — пояснение «Неоплаченные счета на сегодня — период отчёта на эту таблицу не влияет.»

В таблицу попадают все счета, которые не оплачены и не отменены, на сегодняшний день. Для каждого счёта считается, на сколько дней он просрочен: от срока оплаты счёта, а если срок не указан — от даты выставления. Счёт попадает в одну из строк:

| Строка | Какие счета |
| --- | --- |
| «Не просрочено» | Срок оплаты ещё не наступил или наступает сегодня |
| «1-30 дней» | Просрочен на 1–30 дней |
| «31-60 дней» | Просрочен на 31–60 дней |
| «61-90 дней» | Просрочен на 61–90 дней |
| «Больше 90 дней» | Просрочен больше чем на 90 дней. Название строки красное, если в ней есть хоть один счёт |

В каждой строке две цифры: количество счетов (серым) и их сумма. В сумму входит полная сумма каждого счёта.

## Кнопки

| Кнопка / иконка | Что делает | Право |
| --- | --- | --- |
| :icon{name="i-lucide-printer"} «Печать» | Открывает окно печати браузера | `report:view` + `finance:view` |
| :icon{name="i-lucide-download"} «CSV» у таблицы «По месяцам» | Скачивает файл `financial-by-month-<дата>.csv`: «Месяц», «Выставлено», «Получено», «Потрачено», «Итого» | `report:view` + `finance:view` |
| :icon{name="i-lucide-download"} «CSV» у «Расходы по категориям» | Скачивает файл `expenses-by-category-<дата>.csv`: «Категория», «Сумма» | `report:view` + `finance:view` |
| :icon{name="i-lucide-download"} «CSV» у «Дебиторка по срокам» | Скачивает файл `receivables-ageing-<дата>.csv`: «Срок», «Счетов», «Сумма» | `report:view` + `finance:view` |
| «Сбросить» | Очищает даты периода (видна, когда задана хотя бы одна дата) | `report:view` + `finance:view` |

Выгрузки учитывают выбранный период так же, как таблицы на экране.
