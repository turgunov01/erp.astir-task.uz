Отчёт «Производство» находится в меню **Отчёты → Производство**, адрес `/reports/production`. Заголовок страницы — «Производство», в заголовке вкладки браузера — «Производственный отчёт».

Отчёт отвечает на вопрос «какие проекты требуют внимания прямо сейчас». В него входят только живые проекты: **отменённые и архивные проекты в отчёт не попадают**. Удалённые проекты тоже не показываются.

![Отчёт «Производство»](/screenshots/reports-production.png)

## Доступ

Нужно право `report:view` (по умолчанию есть у: Владелец, Администратор, Продюсер, Менеджер проекта, Финансы).

## Фильтр

| Фильтр | Что делает |
| --- | --- |
| Список проектов («Все проекты») | Оставляет в отчёте один выбранный проект. Выбор сохраняется в адресе страницы (`?projectId=…`) |

Периода у этого отчёта нет: все цифры — на текущий момент.

## Итоговые карточки

Над таблицей — четыре карточки. Они считаются по строкам, которые сейчас в таблице (с учётом фильтра по проекту).

| Карточка | Как считается |
| --- | --- |
| «Проектов» | Сколько проектов в отчёте |
| «Сорван срок» | Сколько проектов с сорванным сроком (см. колонку «Дедлайн» ниже). Число красное, если больше нуля |
| «Просроченных задач» | Сумма колонки «Просрочено» по всем проектам. Красное, если больше нуля |
| «Открытых правок» | Сумма колонки «Правки» по всем проектам |

## Таблица

Проекты отсортированы по дедлайну (сначала самые ранние), при одинаковом дедлайне — по коду.

| Колонка | Что показывает и как считается |
| --- | --- |
| «Проект» | Название проекта (ссылка на [карточку проекта](/projects/card)) и рядом серым — код проекта |
| «Статус» | Статус проекта цветным значком |
| «Риск» | Уровень риска проекта цветным значком |
| «Прогресс» | Процент готовности проекта — тот же, что в карточке проекта |
| «Дедлайн» | Дедлайн проекта. Дата красная, если срок сорван: дедлайн уже прошёл, а проект не в статусе «Завершён» |
| «Этапы» | «готово / всего»: сколько этапов проекта в статусе «Завершён» из общего числа этапов |
| «Задачи» | «готово / всего»: сколько задач проекта в статусе «Завершена» или «Утверждена» из всех задач проекта |
| «Просрочено» | Сколько задач с прошедшим дедлайном, которые ещё открыты — в статусе «Бэклог», «Готова к работе», «В работе», «На проверке», «На правках» или «Заблокирована». Красное, если больше нуля |
| «Правки» | Сколько правок по проекту открыто — в статусе «Открыта», «В работе» или «На проверке» |

### Значки статуса проекта

| Статус | Цвет |
| --- | --- |
| «Черновик» | серый |
| «Планирование», «Препродакшен» | голубой |
| «Продакшен», «Постпродакшен» | фиолетовый |
| «У клиента», «Сдача», «Приостановлен» | жёлтый |
| «Завершён» | зелёный |

### Значки риска

| Риск | Цвет |
| --- | --- |
| «Низкий» | зелёный |
| «Средний» | голубой |
| «Высокий» | жёлтый |
| «Критический» | красный |

## Кнопки

| Кнопка / иконка | Что делает | Право |
| --- | --- | --- |
| :icon{name="i-lucide-download"} «CSV» | Скачивает отчёт файлом `production-<дата>.csv` с учётом фильтра по проекту | `report:view` |
| :icon{name="i-lucide-printer"} «Печать» | Открывает окно печати браузера | `report:view` |

## Что в файле CSV

Колонки файла: «Код», «Проект», «Статус», «Риск», «Прогресс, %», «Дедлайн», «Просрочен» (да/нет — сорван ли срок), «Этапов всего», «Этапов готово», «Задач всего», «Задач готово», «Задач просрочено», «Открытых правок».

## Пустой отчёт

Если живых проектов нет (или выбранный проект отменён либо в архиве), вместо таблицы появляется надпись «Живых проектов нет — отчёту не о чем рассказать.»

Общие для всех отчётов правила — печать, выгрузка, ошибки — описаны на странице [Отчёты](/reports/overview).
