Отчёт находится в меню **Отчёты → Время и люди**, адрес `/reports/time`. Заголовок страницы — «Время и люди», в заголовке вкладки браузера — «Отчёт по времени».

Отчёт собирает часы, списанные сотрудниками в [табель](/team/timesheets), и оценивает их по часовой ставке каждого сотрудника. Часы без ставки тоже учитываются, но ничего не стоят — они вынесены в отдельную колонку, чтобы было видно, насколько занижена стоимость.

![Отчёт «Время и люди»](/screenshots/reports-time.png)

## Доступ

Нужно право `report:view` (по умолчанию есть у: Владелец, Администратор, Продюсер, Менеджер проекта, Финансы).

## Фильтры

| Фильтр | Что делает |
| --- | --- |
| «С» / «по» | Учитываются только записи табеля с датой в этом периоде. Пустые поля — всё время |
| Список проектов («Все проекты») | Учитываются только часы, списанные на выбранный проект |
| «Сбросить даты» | Очищает обе даты (видна, когда задана хотя бы одна). Проект не сбрасывает |

Даты и проект сохраняются в адресе страницы, ссылку можно переслать.

## Предупреждение о часах без ставки

Если кто-то из попавших в отчёт сотрудников работает без ставки, над карточками появляется жёлтое предупреждение: «… ч списано людьми без ставки — эти часы в стоимость не вошли. Итог ниже занижен ровно на них.» Чтобы исправить, задайте ставку в карточке сотрудника — см. [Сотрудники](/team/employees).

## Итоговые карточки

| Карточка | Как считается |
| --- | --- |
| «Человек» | Сколько сотрудников списали часы в выбранном периоде (и проекте) |
| «Часов» | Сумма всех списанных часов |
| «Стоимость» | Сумма стоимости по всем сотрудникам |

## Таблица

Одна строка на сотрудника. Сотрудники отсортированы по числу часов — сначала те, кто списал больше всех.

| Колонка | Как считается |
| --- | --- |
| «Сотрудник» | Имя и фамилия |
| «Должность» | Должность из карточки сотрудника |
| «Отдел» | Отдел сотрудника; «—», если отдел не указан |
| «Ставка» | Текущая часовая ставка из карточки сотрудника. Если ставка не указана — красная надпись «не задана» |
| «Часов» | Сумма часов сотрудника в табеле за период |
| «Без ставки» | Часы, которые не вошли в стоимость, потому что ставка не задана или равна нулю. Красное, если больше нуля |
| «Стоимость» | «Часов» × «Ставка» |
| «Проектов» | На сколько разных проектов сотрудник списывал часы |

::note
Стоимость считается по ставке, которая указана у сотрудника сейчас, а не на дату записи в табеле. Если ставку меняли, старые часы пересчитаются по новой.
::

::note
Ставка и стоимость в этом отчёте всегда показываются в долларах (USD).
::

## Кнопки

| Кнопка / иконка | Что делает | Право |
| --- | --- | --- |
| :icon{name="i-lucide-download"} «CSV» | Скачивает отчёт файлом `time-<дата>.csv` с учётом периода и проекта | `report:view` |
| :icon{name="i-lucide-printer"} «Печать» | Открывает окно печати браузера | `report:view` |
| «Сбросить даты» | Очищает даты периода | `report:view` |

## Что в файле CSV

Колонки: «Сотрудник», «Должность», «Отдел», «Ставка», «Часов», «Часов без ставки», «Стоимость», «Проектов».

## Пустой отчёт

Если за период (и по выбранному проекту) никто не списывал часы — надпись «За выбранный период часы никто не списывал.»

Общие правила отчётов — на странице [Отчёты](/reports/overview).
