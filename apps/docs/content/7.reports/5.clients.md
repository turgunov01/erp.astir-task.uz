Отчёт находится в меню **Отчёты → Клиенты**, адрес `/reports/clients`. Заголовок страницы — «Клиенты», в заголовке вкладки браузера — «Отчёт по клиентам».

Отчёт строится от счетов: по каждому клиенту — сумма выставленных счетов, полученные по ним платежи и остаток долга.

![Отчёт «Клиенты»](/screenshots/reports-clients.png)

::note
Платёж, не привязанный к счёту, в этот отчёт не попадает — такие деньги видно в [финансовом отчёте](/reports/financial).
::

## Доступ

Нужно право `report:view` (по умолчанию есть у: Владелец, Администратор, Продюсер, Менеджер проекта, Финансы).

## Фильтр периода

Поля «С» и «по» отбирают **счета по дате выставления**. Пустые поля — все счета за всё время. Кнопка «Сбросить» очищает обе даты. Даты сохраняются в адресе страницы.

На экране показываются только клиенты, которым в выбранном периоде выставлен хотя бы один счёт.

## Предупреждение о нескольких валютах

Если у клиентов в таблице разные валюты, над карточками появляется жёлтое предупреждение: «Клиенты в разных валютах. Итоги ниже складывают их как одну — читайте строки, а не сумму.» Строки таблицы при этом показаны каждая в своей валюте.

## Итоговые карточки

| Карточка | Как считается |
| --- | --- |
| «Выставлено» | Сумма колонки «Выставлено» по всем клиентам в таблице |
| «Оплачено» | Сумма колонки «Оплачено» |
| «Остаток» | Сумма колонки «Остаток». Красное, если больше нуля |

Суммы карточек показываются в валюте первого клиента в таблице.

## Таблица

Клиенты отсортированы по названию.

| Колонка | Как считается |
| --- | --- |
| «Клиент» | Название клиента |
| «Статус» | Статус клиента цветным значком: «Активен» — зелёный, «Неактивен» и «В архиве» — серый |
| «Проектов» | Сколько всего проектов у клиента (без учёта периода) |
| «Счетов» | Сколько счетов клиенту выставлено в периоде |
| «Выставлено» | Сумма этих счетов |
| «Оплачено» | Сумма платежей в статусе «Оплачен», привязанных к этим счетам (дата платежа значения не имеет) |
| «Остаток» | «Выставлено» минус «Оплачено». Красное, если больше нуля |
| «Срок оплаты» | Среднее число дней от выставления счёта до последнего платежа по нему, например «12 дн.». Считается только по полностью оплаченным счетам; если таких нет — «—» |

Валюта строки — валюта первого счёта клиента в периоде.

## Кнопки

| Кнопка / иконка | Что делает | Право |
| --- | --- | --- |
| :icon{name="i-lucide-download"} «CSV» | Скачивает отчёт файлом `clients-<дата>.csv` с учётом периода | `report:view` |
| :icon{name="i-lucide-printer"} «Печать» | Открывает окно печати браузера | `report:view` |
| «Сбросить» | Очищает даты периода | `report:view` |

## Что в файле CSV

Колонки: «Клиент», «Статус», «Проектов», «Счетов», «Валюта», «Выставлено», «Оплачено», «Остаток», «Средний срок оплаты, дней».

::note
В файл попадают все клиенты, в том числе те, кому в периоде ничего не выставлялось (у них нули), — на экране такие строки скрыты.
::

## Пустой отчёт

Если в периоде никому ничего не выставлялось — надпись «За выбранный период клиентам ничего не выставлялось.»
