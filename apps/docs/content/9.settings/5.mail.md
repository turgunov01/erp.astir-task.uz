Вкладка находится в разделе **Настройки → Почта**, адрес `/settings?tab=mail`. Чтобы открыть её из раздела, щёлкните подпись вкладки «Почта».

Через эти параметры приложение отправляет письма: коды подтверждения и уведомления.

![Вкладка «Почта»](/screenshots/settings-mail.png)

::warning
Пока SMTP не заполнен, коды подтверждения и уведомления никуда не уходят — они пишутся в лог сервера. Регистрация формально работает, но живой человек кода не получит.
::

## Доступ

- Видеть вкладку: право `settings:view` (по умолчанию есть у: Владелец, Администратор).
- Менять, сохранять и отправлять проверочное письмо: право `settings:manage` (по умолчанию есть у: Владелец, Администратор). Без него поля неактивны и кнопок нет.

## Поля

| Поле | Ограничения | Пояснение |
| --- | --- | --- |
| «Сервер» | До 200 символов | Адрес почтового сервера |
| «Порт» | Целое число от 1 до 65535 | Подсказка: «465 — TLS сразу, остальные — STARTTLS.» |
| «Пользователь» | До 200 символов | Логин на почтовом сервере |
| «Пароль» | До 200 символов | Если пароль уже сохранён, в поле видна надпись «Сохранён — оставьте пустым, чтобы не менять»; если нет — «Не задан» |
| «Отправитель» | До 200 символов | Имя и адрес отправителя |

::note
Сохранённый пароль обратно не показывается — подсмотреть его на этой странице нельзя. Если оставить поле пустым, сохранённый пароль не изменится; чтобы сменить пароль, введите новый и нажмите «Сохранить».
::

## Кнопки

| Кнопка | Что делает | Право |
| --- | --- | --- |
| «Сохранить» | Сохраняет параметры почты. Пароль отправляется, только если он введён | `settings:manage` |
| «Отправить проверочное письмо себе» | Отправляет письмо на почту вашей учётной записи по уже сохранённым параметрам. Пока идёт отправка — «Отправляю...» | `settings:manage` |

### Результат проверки

Под кнопками появляется плашка:

| Плашка | Что означает |
| --- | --- |
| Зелёная «Письмо отправлено на …» | Сервер принял письмо — проверьте почтовый ящик |
| Жёлтая «SMTP не настроен — письмо записано в лог сервера, а не отправлено» | Параметры SMTP не заданы |
| Жёлтая с текстом ошибки | Отправить не удалось, например из-за неверных параметров |

::tip
Сначала нажмите «Сохранить», потом «Отправить проверочное письмо себе»: проверка использует сохранённые параметры, а не те, что введены в поля.
::
