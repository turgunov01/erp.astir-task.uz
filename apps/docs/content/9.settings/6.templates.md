Вкладка находится в разделе **Настройки → Шаблоны пайплайна**, адрес `/settings?tab=templates`. Чтобы открыть её из раздела, щёлкните подпись вкладки «Шаблоны пайплайна».

Шаблон задаёт список этапов, которыми наполняется новый проект. Этапы из стандартного пайплайна сохраняют свой вес и отдел; незнакомое название тоже станет этапом — с весом 1 и без отдела.

![Вкладка «Шаблоны пайплайна»](/screenshots/settings-templates.png)

## Доступ

- Видеть список шаблонов: право `settings:view` (по умолчанию есть у: Владелец, Администратор).
- Создавать, изменять и удалять: право `settings:manage` (по умолчанию есть у: Владелец, Администратор). Без него нет формы и кнопок «Изменить» / «Удалить».

## Как шаблон применяется к проекту

В форме создания проекта (см. [Создание и редактирование проекта](/projects/create)) выбирается один из встроенных шаблонов: «2D-анимация», «3D-анимация», «Рекламный ролик», «Моушн-дизайн», «Серия сериала». Если на этой вкладке есть шаблон **с точно таким же названием**, новый проект получает этапы из него, а не встроенные.

::note
Уже созданные проекты от изменения или удаления шаблона не меняются — шаблон влияет только на новые проекты.
::

## Список шаблонов

Каждая строка — один шаблон:

- название шаблона; у шаблона, отмеченного «Предлагать этот шаблон первым», рядом серая метка «по умолчанию»;
- под названием — число этапов и сами этапы через стрелку, например «4 этапа: Бриф → Раскадровка → Анимация → Сдача».

Шаблоны отсортированы так: сначала отмеченный «по умолчанию», затем по названию.

Если своих шаблонов нет, вместо списка — надпись «Своих шаблонов пока нет — проекты создаются по встроенному пайплайну.»

## Форма шаблона

Под списком — форма. Её заголовок «Новый шаблон» или, после нажатия «Изменить» в строке, «Изменение шаблона».

| Поле | Ограничения | Пояснение |
| --- | --- | --- |
| «Название» | Обязательное, от 2 до 80 символов | Чтобы шаблон заменял встроенный, название должно совпадать с ним полностью |
| «Описание» | Необязательное, до 400 символов | — |
| «Этапы — по одному в строке, в нужном порядке» | Хотя бы один этап, не больше 40; каждое название до 80 символов | Пустые строки пропускаются. Порядок строк — порядок этапов. Без этапов сохранение отклоняется с ошибкой «Нужен хотя бы один этап» |
| «Предлагать этот шаблон первым» | Флажок | Отметка может стоять только у одного шаблона: при сохранении она снимается со всех остальных |

## Кнопки

| Кнопка | Что делает | Право |
| --- | --- | --- |
| «Создать» | Сохраняет новый шаблон (активна, когда заполнено название) | `settings:manage` |
| «Сохранить» | Сохраняет изменения редактируемого шаблона | `settings:manage` |
| «Отмена» | Выходит из редактирования и очищает форму | `settings:manage` |
| «Изменить» (в строке) | Загружает шаблон в форму для правки | `settings:manage` |
| «Удалить» (в строке) | Открывает окно «Удаление шаблона» с вопросом «Удалить шаблон «…»?» и пояснением «Уже созданные проекты не изменятся — шаблон влияет только на новые.» Кнопка «Удалить» в окне удаляет шаблон | `settings:manage` |

::warning
Удаление шаблона необратимо: восстановить его можно только создав заново.
::
