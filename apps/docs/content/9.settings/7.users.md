Вкладка находится в разделе **Настройки → Пользователи**, адрес `/settings?tab=users`. Чтобы открыть её из раздела, щёлкните подпись вкладки «Пользователи».

Здесь все учётные записи, включая тех, у кого нет карточки сотрудника, — например, портальных пользователей клиентов. Приём на работу, должность и ставка задаются в разделе [Сотрудники](/team/employees) (ссылка «сотрудниках» в пояснении вверху вкладки ведёт туда же).

![Вкладка «Пользователи»](/screenshots/settings-users.png)

## Доступ

Вкладка видна только с правом `user:manage` (по умолчанию есть у: Владелец, Администратор). Кроме того, нужно право `settings:view`, чтобы открыть сам раздел «Настройки».

## Поиск

Поле «Поиск по имени или почте...» ищет по имени, фамилии и почте (без учёта регистра). Список показывает по 20 записей; если страниц больше одной, внизу появляются кнопки «Назад» и «Дальше» и надпись «Страница N из M».

Сначала идут активные учётные записи, затем отключённые; внутри — по имени.

## Таблица

| Колонка | Что показывает |
| --- | --- |
| «Пользователь» | Имя и фамилия, ниже — почта и через точку: должность (если есть карточка сотрудника), «портал клиента …» (для учётной записи клиента) или «без карточки сотрудника» |
| «Роль» | Выпадающий список роли — см. ниже |
| «Почта» | Подтверждена ли почта: «подтверждена» или ссылка «подтвердить вручную» |
| «Доступ» | Кнопка «Отключить» (красная) для активной записи или «Включить» для отключённой. Для вашей собственной записи — надпись «это вы» |

### Выбор роли

Список ролей разделён на две группы:

- «Стандартные роли» — Владелец, Администратор, Продюсер, Менеджер проекта, Арт-директор, Художник, Клиент, Финансы;
- «Свои роли» — роли, созданные студией на вкладке [Роли и доступ](/settings/roles). Группа видна, если такие роли есть.

Изменение применяется сразу после выбора, без отдельной кнопки сохранения.

- Если выбрать стандартную роль, «своя» роль у человека снимается.
- Если выбрать «свою» роль, человек получает её права, а системной ролью становится роль, на которой она построена.
- Свою собственную роль сменить нельзя — для вашей строки список неактивен.

::note
Назначить «свою» роль можно, только если у вас самих есть все её права и она не построена на роли выше вашей. Иначе появится ошибка, например «Нельзя назначить роль с правами, которых нет у вас: …».
::

## Кнопки

| Кнопка | Что делает | Право |
| --- | --- | --- |
| Список «Роль» | Меняет роль учётной записи | `user:manage` |
| «подтвердить вручную» | Отмечает почту как подтверждённую — для студии, где отправка писем ещё не настроена (см. [Почта](/settings/mail)) | `user:manage` |
| «Отключить» | Отключает учётную запись: человек больше не сможет войти в систему. Окна подтверждения нет | `user:manage` |
| «Включить» | Возвращает доступ отключённой учётной записи | `user:manage` |
| «Назад» / «Дальше» | Листают страницы списка | `user:manage` |

::warning
Собственную учётную запись отключить нельзя, и собственную роль сменить нельзя — это защита от ситуации, когда в студии не остаётся никого, кто может вернуть доступ.
::

Если изменение не удалось, над таблицей появляется красная надпись с причиной (по умолчанию «Не удалось изменить учётную запись»).
